# 第 3 章 数据结构

# 10. 数组

## 学习目标

- 掌握一维、多维数组
- 学会 Arrays 工具
- 理解数组长度固定

## 10.1 创建

```java
int[] a = {1, 2, 3};
int[] b = new int[5];  // 默认 0
int[] c = new int[]{1, 2, 3};
```

## 10.2 访问

```java
int x = a[0];
a[0] = 10;
int len = a.length;
```

## 10.3 多维数组

```java
int[][] m = {
    {1, 2, 3},
    {4, 5, 6}
};
int v = m[1][2];  // 6
```

每行长度可不同。

## 10.4 Arrays 工具

```java
import java.util.Arrays;

Arrays.toString(a)           // "[1, 2, 3]"
Arrays.equals(a, b)         // 内容比较
Arrays.sort(a)              // 排序
Arrays.copyOf(a, 10)       // 复制
Arrays.fill(a, 0)          // 填充
Arrays.binarySearch(a, x)  // 二分（需排序）
```

## 10.5 遍历

```java
for (int x : a) {
    System.out.println(x);
}
```

## 10.6 数组引用

```java
int[] a = {1, 2, 3};
int[] b = a;       // 同一对象
b[0] = 10;
System.out.println(a[0]);  // 10

int[] c = a.clone();  // 浅拷贝
c[0] = 20;
System.out.println(a[0]);  // 10
```

## 10.7 泛型数组陷阱

```java
List<String>[] lists = new List[10];  // 警告
List<String>[] lists2 = (List<String>[]) new List<?>[10];  // 抑制
```

## 10.8 数组与 List 转换

```java
int[] a = {1, 2, 3};
List<Integer> list = Arrays.stream(a).boxed().toList();
int[] back = list.stream().mapToInt(Integer::intValue).toArray();
```

## 10.9 性能

- 基本类型数组最快
- 对象数组每个元素引用
- 缓存友好

## 10.10 陷阱

- 数组长度固定
- 越界 `ArrayIndexOutOfBoundsException`
- `==` 比较身份

## 小结

- 数组长度固定
- Arrays 工具强大
- clone 浅拷贝
- 基本类型快
