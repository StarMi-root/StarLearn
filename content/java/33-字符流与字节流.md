# 第 8 章 文件与 IO

# 33. 字符流与字节流

## 学习目标

- 理解 Reader/Writer
- 掌握 Input/OutputStream
- 学会缓冲流

## 33.1 字节流

```java
InputStream
├── FileInputStream
├── BufferedInputStream
├── DataInputStream
└── ObjectInputStream

OutputStream
├── FileOutputStream
├── BufferedOutputStream
├── DataOutputStream
└── ObjectOutputStream
```

## 33.2 字符流

```java
Reader
├── FileReader
├── BufferedReader
└── InputStreamReader

Writer
├── FileWriter
├── BufferedWriter
└── OutputStreamWriter
```

## 33.3 桥接

```java
InputStreamReader in = new InputStreamReader(System.in);
OutputStreamWriter out = new OutputStreamWriter(System.out);
```

## 33.4 缓冲

```java
BufferedReader br = new BufferedReader(new FileReader("data.txt"));
BufferedWriter bw = new BufferedWriter(new FileWriter("out.txt"));
```

## 33.5 陷阱

- 字节流读文本
- 编码不匹配
- 忘记 flush

## 33.6 最佳实践

- 文本用字符流
- 二进制用字节流
- 缓冲流
- 显式编码

## 33.7 标准流

```java
System.in / System.out / System.err
```

重定向：

```java
System.setOut(new PrintStream("log.txt"));
```

## 小结

- 字节流二进制
- 字符流文本
- 缓冲提升
- 编码显式
