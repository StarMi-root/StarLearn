# 第 15 章 工程化

# 57. 项目结构

## 学习目标

- 掌握标准目录
- 学会包组织
- 理解模块划分

## 57.1 标准结构

```
src/
  main/
    java/
      com/example/
        model/
        service/
        repository/
        api/
        config/
    resources/
      application.yml
      db/migration/
  test/
    java/
      com/example/
    resources/
```

## 57.2 包组织

- **按功能**：`user`, `order`, `payment`
- **按层**：`controller`, `service`, `repository`

## 57.3 模块

```
myapp/
  myapp-api/
  myapp-core/
  myapp-web/
  myapp-test/
```

## 57.4 资源

```
application.yml
logback.xml
i18n/
templates/
static/
```

## 57.5 陷阱

- 包过深
- 循环依赖
- 资源混乱

## 57.6 最佳实践

- 单一职责
- 清晰命名
- 模块化

## 小结

- 标准目录
- 按功能/层
- 模块化
- 资源集中
