# 第 7 章 异常

# 28. 自定义异常

## 学习目标

- 学会定义异常类
- 设计异常层级
- 掌握异常消息

## 28.1 基本用法

```java
public class AppException extends RuntimeException {
    public AppException(String message) {
        super(message);
    }

    public AppException(String message, Throwable cause) {
        super(message, cause);
    }
}
```

## 28.2 异常层级

```java
public class AppException extends RuntimeException { }
public class ConfigException extends AppException { }
public class DataException extends AppException { }
```

## 28.3 携带上下文

```java
public class ValidationException extends Exception {
    private final String field;
    private final Object value;

    public ValidationException(String field, Object value) {
        super("Invalid value for field: " + field);
        this.field = field;
        this.value = value;
    }

    public String getField() { return field; }
    public Object getValue() { return value; }
}
```

## 28.4 抛出

```java
if (age < 0) {
    throw new ValidationException("age", age);
}
```

## 28.5 捕获

```java
try {
    ...
} catch (ValidationException e) {
    log.error("validation failed: {} = {}", e.getField(), e.getValue());
}
```

## 28.6 保留原始异常

```java
try {
    json = parse(input);
} catch (Exception e) {
    throw new DataException("parse failed", e);
}
```

## 28.7 受检 vs 非受检

- 业务异常：非受检
- 系统异常：受检
- 混合策略

## 28.8 陷阱

- 异常过多
- 消息模糊
- 丢失原因

## 28.9 最佳实践

- 层级清晰
- 消息具体
- 保留 cause
- 不要吞异常

## 小结

- 继承 RuntimeException
- 携带上下文
- 保留原因
- 层级设计
