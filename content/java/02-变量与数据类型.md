# 第 1 章 入门基础

# 2. 变量与数据类型

## 学习目标

- 掌握 8 种基本类型
- 理解引用类型
- 学会类型转换

## 2.1 基本类型

| 类型 | 大小 | 范围 | 默认值 |
|------|------|------|--------|
| boolean | 1 bit | true/false | false |
| byte | 8 位 | -128~127 | 0 |
| short | 16 位 | -32768~32767 | 0 |
| int | 32 位 | -2^31~2^31-1 | 0 |
| long | 64 位 | -2^63~2^63-1 | 0L |
| float | 32 位 | ~7 位有效 | 0.0f |
| double | 64 位 | ~15 位有效 | 0.0d |
| char | 16 位 | \u0000~\uffff | '\u0000' |

## 2.2 字面量

```java
int a = 10;
long b = 100_000L;
float c = 3.14f;
double d = 3.14;
char e = 'A';
String s = "hello";
boolean f = true;
```

下划线可分隔：`1_000_000`。

## 2.3 变量声明

```java
int count = 0;
final int PI = 3; // 常量
```

`final` 声明后不可修改。

## 2.4 引用类型

```java
String s = "hello";
int[] arr = {1, 2, 3};
Object obj = new Object();
```

引用类型为 null 表示不指向对象。

## 2.5 自动类型转换

小转大自动：

```java
int x = 5;
long y = x;     // OK
double z = x;   // OK
```

大转小需显式：

```java
long l = 100L;
int i = (int) l; // 显式
```

## 2.6 装箱与拆箱

```java
Integer box = 42;        // 装箱
int n = box;             // 拆箱
```

注意：`Integer` 缓存 -128~127，`==` 比较陷阱。

## 2.7 陷阱

```java
int a = 2;
int b = 3;
System.out.println((a + b) * 257); // int 溢出
System.out.println(2L + 3);        // 自动提升为 long
```

## 2.8 默认值

- 成员变量有默认值（0、false、null）
- 局部变量必须初始化

## 小结

- 8 种基本类型
- 引用类型可为 null
- 大转小需显式
- 注意整型溢出
