# 第 1 章 入门基础

# 3. 运算符与表达式

## 学习目标

- 掌握算术、比较、逻辑、位运算
- 理解三元运算符
- 避免溢出

## 3.1 算术

```java
+  -  *  /  %
```

注意：

```java
int a = 7 / 2;    // 3（整数除法）
int b = 7 % 2;    // 1
int c = -7 % 2;   // -1（符号跟随被除数）
```

## 3.2 自增自减

```java
int x = 5;
x++;   // 后置，返回旧值
++x;   // 前置，返回新值
```

## 3.3 比较

```java
==  !=  <  >  <=  >=
```

对象用 `.equals()`，不用 `==`。

## 3.4 逻辑

```java
&&  ||  !
```

短路求值。

## 3.5 三元

```java
int max = a > b ? a : b;
```

可嵌套，但避免复杂。

## 3.6 位运算

```java
&  |  ^  ~  <<  >>  >>>
```

```java
1 << 3    // 8
5 & 3     // 1
```

## 3.7 赋值

```java
=  +=  -=  *=  /=  %=  &=  |=  ^=  <<=  >>=
```

## 3.8 整数溢出

```java
int max = Integer.MAX_VALUE; // 2147483647
int over = max + 1;          // -2147483648（溢出）
```

用 `long` 或 `Math.addExact` 检测。

## 3.9 浮点比较

```java
0.1 + 0.2 == 0.3  // false
Math.abs(0.1 + 0.2 - 0.3) < 1e-9  // true
```

## 3.10 运算优先级

```
()
++  --
* / %
+ -
<< >>
< > <= >=
== !=
&
^
|
&&
||
? :
= += -= ...
```

## 3.11 陷阱

- 整数除法丢小数
- 位运算优先级低于 ==
- `a = b = 0` 合法（链式赋值）
- `&` 与 `&&` 不同

## 小结

- 整数除法向下取整
- 浮点比较用容差
- 位运算注意优先级
- 避免溢出
