# 第 4 章 方法

# 15. 方法定义与调用

## 学习目标

- 掌握方法定义
- 学会重载
- 理解可变参数

## 15.1 基本语法

```java
public static int add(int a, int b) {
    return a + b;
}
```

`static` 类方法，`public` 访问级别。

## 15.2 实例方法

```java
public int doubleIt(int x) {
    return x * 2;
}
```

## 15.3 重载

```java
int add(int a, int b) { return a + b; }
double add(double a, double b) { return a + b; }
int add(int a, int b, int c) { return a + b + c; }
```

方法名相同、参数不同。

## 15.4 可变参数

```java
public static int sum(int... nums) {
    int total = 0;
    for (int n : nums) total += n;
    return total;
}

sum(1, 2, 3);  // 6
sum(new int[]{1, 2});  // 3
```

## 15.5 方法引用

```java
int r = Math::addExact.apply(1, 2);  // 需要接口
```

## 15.6 递归

```java
public static int factorial(int n) {
    if (n <= 1) return 1;
    return n * factorial(n - 1);
}
```

## 15.7 void 方法

```java
public static void printAll(List<String> items) {
    for (String s : items) {
        System.out.println(s);
    }
}
```

## 15.8 陷阱

- 参数过多（> 5 个）
- 方法太长（> 20 行）
- 命名不清晰
- 返回 null

## 15.9 最佳实践

- 单一职责
- 参数对象化（record）
- 用 Optional 替代 null

## 小结

- 重载同名不同参
- 可变参数 int...
- 方法短小
- 避免返回 null
