# 第 6 章 包与模块化

# 24. 包与导入

## 学习目标

- 掌握 package 声明
- 学会 import
- 理解包结构

## 24.1 包声明

```java
package com.example.app;

public class MyClass {
}
```

文件名：`MyClass.java`
目录：`com/example/app/MyClass.java`

## 24.2 import

```java
import java.util.List;
import java.util.Map;
import static java.lang.Math.PI;

List<String> list = new ArrayList<>();
System.out.println(PI);
```

## 24.3 通配导入

```java
import java.util.*;  // 不推荐
```

## 24.4 包结构

```
com/example/app/
  model/
    User.java
  service/
    UserService.java
  api/
    UserController.java
```

## 24.5 陷阱

- 包名冲突
- 通配导入
- 循环依赖

## 24.6 最佳实践

- 域名反写
- 小写
- 按功能分包
