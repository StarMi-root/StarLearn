# 第 5 章 面向对象

# 20. 抽象类与接口

## 学习目标

- 掌握 abstract
- 学会 interface
- 理解 default 方法

## 20.1 抽象类

```java
public abstract class Shape {
    public abstract double area();

    public void describe() {
        System.out.println("Shape area=" + area());
    }
}

public class Circle extends Shape {
    private double r;
    public Circle(double r) { this.r = r; }
    public double area() {
        return Math.PI * r * r;
    }
}
```

## 20.2 接口

```java
public interface Drawable {
    void draw();

    default String describe() {
        return "Drawable";
    }

    static int constant() {
        return 42;
    }
}
```

## 20.3 多实现

```java
public class Widget implements Drawable, Serializable {
    public void draw() { ... }
}
```

## 20.4 default 方法

```java
public interface Shape {
    double area();

    default double perimeter() {
        return 0;
    }
}
```

## 20.5 私有方法（Java 9+）

```java
public interface Shape {
    private void helper() {
        // 仅接口内使用
    }
}
```

## 20.6 抽象类 vs 接口

| 特性 | 抽象类 | 接口 |
|------|--------|------|
| 继承 | 单 | 多 |
| 字段 | 任意 | 常量 |
| 构造器 | 有 | 无 |
| 方法实现 | 可 | default/static |
| 场景 | 共享代码 | 契约 |

## 20.7 陷阱

- 接口方法隐式 public abstract
- 字段隐式 public static final
- 默认方法冲突

## 20.8 最佳实践

- 接口表达能力
- 抽象类共享实现
- default 少用

## 小结

- 抽象类共享
- 接口契约
- default 扩展
- 多实现
