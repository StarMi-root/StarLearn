# 第 5 章 面向对象

# 21. 内部类与匿名类

## 学习目标

- 掌握四种内部类
- 学会匿名类
- 理解作用域

## 21.1 静态内部类

```java
public class Outer {
    public static class StaticInner {
        // 不能访问 Outer 的实例成员
    }
}
```

## 21.2 非静态内部类

```java
public class Outer {
    private int x = 10;

    public class Inner {
        public void use() {
            System.out.println(x);  // 可访问
        }
    }
}
```

## 21.3 局部类

```java
public void method() {
    class Local {
        // 仅方法内
    }
}
```

## 21.4 匿名类

```java
Runnable r = new Runnable() {
    public void run() {
        System.out.println("run");
    }
};
```

## 21.5 Lambda 替代

```java
Runnable r = () -> System.out.println("run");
```

简单优先 Lambda。

## 21.6 陷阱

- 内部类捕获变量必须 effectively final
- 匿名类不能访问局部非 final 变量
- 内存泄漏（持有外部引用）

## 21.7 应用场景

- 事件监听
- 策略模式
- 比较器

```java
list.sort(Comparator.comparingInt(Student::getScore));
```

## 21.8 最佳实践

- 简单回调 Lambda
- 复杂状态内部类
- 避免内存泄漏

## 小结

- 四种内部类
- 匿名类 Lambda 替代
- 注意捕获 final
- 避免泄漏
