# 第 9 章 泛型

# 36. 泛型陷阱

## 学习目标

- 避免泛型错误
- 理解类型擦除
- 学会正确处理

## 36.1 原生类型

```java
List list = new ArrayList();  // 警告
list.add("a");
list.add(1);  // 编译过，运行时错
```

## 36.2 数组

```java
List<String>[] lists = new List[10];  // 警告
```

## 36.3 new 类型参数

```java
public <T> T create() {
    return new T();  // 编译错
}
```

## 36.4 类字面量

```java
public <T> Class<T> get() {
    return T.class;  // 编译错
}
```

## 36.5 通配符陷阱

```java
List<?> list = ...;
list.add("a");  // 编译错
Object o = list.get(0);  // OK
```

## 36.6 类型转换

```java
List<String> a = ...;
List<Integer> b = a;  // 编译错
```

## 36.7 继承

```java
// List<String> 不是 List<Object> 的子类型
```

## 36.8 反射

```java
Field f = obj.getClass().getField("list");
// 泛型信息丢失
```

## 36.9 最佳实践

- 避免原生类型
- 通配符正确
- 反射谨慎

## 36.10 检查清单

- [ ] 无原生类型
- [ ] 通配符符合 PECS
- [ ] 不 new 类型参数
- [ ] 不 cast 不同泛型

## 小结

- 避免原生
- 通配符 PECS
- 类型擦除限制
- 反射谨慎
