# 第 7 章 异常

# 27. 异常处理

## 学习目标

- 掌握 try/catch/finally
- 学会 throws
- 理解异常层级

## 27.1 基本语法

```java
try {
    int x = 1 / 0;
} catch (ArithmeticException e) {
    System.out.println(e.getMessage());
} finally {
    System.out.println("cleanup");
}
```

## 27.2 异常层级

```
Throwable
├── Error
└── Exception
    ├── RuntimeException
    │   ├── NullPointerException
    │   ├── IllegalArgumentException
    │   └── ArrayIndexOutOfBoundsException
    ├── IOException
    ├── SQLException
    └── ...
```

## 27.3 受检 vs 非受检

- **受检**（checked）：必须处理或声明
- **非受检**（unchecked）：RuntimeException 子类

```java
public void read() throws IOException {  // 受检
    ...
}
public void compute() {  // 非受检
    // 可能 NullPointerException
}
```

## 27.4 throws 声明

```java
public void process() throws IOException, SQLException {
    ...
}
```

## 27.5 多 catch

```java
try {
    ...
} catch (IOException e) {
    ...
} catch (SQLException e) {
    ...
}
```

## 27.6 抛出异常

```java
if (x < 0) {
    throw new IllegalArgumentException("x must be >= 0");
}
```

## 27.7 陷阱

- 吞异常
- catch 太宽
- 丢失原始异常

## 27.8 最佳实践

- 捕获具体异常
- finally 清理
- 异常消息具体
- 保留原始异常

## 27.9 异常链

```java
try {
    ...
} catch (IOException e) {
    throw new RuntimeException("wrapper", e);  // 保留 e
}
```

## 小结

- 受检必须处理
- 非受检自由
- 异常链保留
- 消息具体
