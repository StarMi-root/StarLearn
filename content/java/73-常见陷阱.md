# 第 20 章 最佳实践

# 73. 常见陷阱

## 学习目标

- 避免常见陷阱
- 理解根因
- 学会修复

## 73.1 可变默认值

```java
// 差
public List<String> items = new ArrayList<>();  // 共享
```

## 73.2 浮点比较

```java
// 差
0.1 + 0.2 == 0.3

// 好
Math.abs(0.1 + 0.2 - 0.3) < 1e-9
```

## 73.3 字符串拼接

```java
// 差
String s = "";
for (char c : chars) s += c;

// 好
StringBuilder sb = new StringBuilder();
```

## 73.4 深拷贝

```java
// 嵌套集合
a = new ArrayList<>(b);  // 浅拷贝
```

## 73.5 异常吞掉

```java
// 差
try { ... } catch (Exception e) { }

// 好
try { ... } catch (SpecificException e) { log.error("...", e); }
```

## 73.6 循环变量捕获

```java
// Lambda 捕获
for (int i = 0; i < n; i++) {
    Thread t = new Thread(() -> System.out.println(i));  // i 被修改
}
```

## 73.7 全局状态

```java
// 差
public static int counter = 0;

// 好
private int counter;
```

## 73.8 比较陷阱

```java
// 差
if (x == null)

// 好
if (x != null)
```

## 73.9 迭代修改

```java
// 差
for (String s : list) {
    if (cond) list.remove(s);
}

// 好
list.removeIf(s -> cond);
```

## 73.10 最佳实践

- 不可变对象
- 显式编码
- 具体异常
- 最小可见性

## 小结

- 陷阱大多可避免
- 清单自查
- 代码审查
