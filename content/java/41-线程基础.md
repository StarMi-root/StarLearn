# 第 11 章 并发

# 41. 线程基础

## 学习目标

- 掌握 Thread 创建
- 学会 Runnable
- 理解线程生命周期

## 41.1 创建线程

```java
// 方式 1：继承 Thread
class MyThread extends Thread {
    public void run() {
        System.out.println("running");
    }
}
new MyThread().start();
```

## 41.2 Runnable

```java
Runnable r = () -> System.out.println("running");
new Thread(r).start();
```

## 41.3 线程生命周期

- NEW
- RUNNABLE
- BLOCKED
- WAITING
- TERMINATED

## 41.4 常用方法

```java
thread.start();
thread.join();
thread.setName("worker");
thread.setDaemon(true);
thread.interrupt();
```

## 41.5 陷阱

- start() 多次
- run() 直接调用
- 未 join

## 41.6 最佳实践

- Runnable 优先
- 设置名称
- 守护线程

## 小结

- Runnable 简洁
- start 启动
- join 等待
- 守护线程
