# 第 1 章 入门基础

# 4. 用户输入与输出

## 学习目标

- 掌握 Scanner 读入
- 学会 System.out 输出
- 理解格式化

## 4.1 读入

```java
import java.util.Scanner;

Scanner sc = new Scanner(System.in);
System.out.print("名字：");
String name = sc.nextLine();
System.out.print("年龄：");
int age = sc.nextInt();
sc.close();
```

`nextInt()` 后需 `nextLine()` 吞掉换行：

```java
sc.nextInt();
sc.nextLine();  // 消耗换行
```

## 4.2 输出

```java
System.out.println("hello");
System.out.print("hello");  // 不换行
System.out.printf("%d %s%n", 42, "x");
```

## 4.3 printf 格式

```java
%d  整数
%s  字符串
%f  浮点
%x  十六进制
%b  布尔
%n  换行
%05d  补零
%10s  对齐
```

```java
System.out.printf("%.2f%n", 3.14159);  // 3.14
System.out.printf("%05d%n", 42);       // 00042
```

## 4.4 String.format

```java
String s = String.format("%s is %d", "Alice", 30);
System.out.println(s);
```

## 4.5 读文件

```java
Scanner sc = new Scanner(new File("data.txt"));
while (sc.hasNext()) {
    System.out.println(sc.nextLine());
}
```

## 4.6 输出编码

```java
// 显式 UTF-8
System.out.print("\u00e9");  // é
```

## 4.7 陷阱

- `nextInt` 与 `nextLine` 混用
- 忘记 close Scanner
- 整数除法

## 4.8 最佳实践

- 读入后校验
- 用 try-with-resources 管理 Scanner
- 用 StringBuilder 拼接

## 小结

- Scanner 读入
- printf 格式化
- 注意换行吞噬
