# 第 4 章 方法

# 16. 参数与返回值

## 学习目标

- 理解值传递与引用传递
- 学会参数校验
- 避免陷阱

## 16.1 值传递

Java **只有值传递**：

```java
static void swap(int a, int b) {
    int t = a; a = b; b = t;
}
// 调用后原变量不变
```

## 16.2 引用传值

```java
static void modify(List<String> list) {
    list.add("x");  // 修改原列表
}
static void reassign(List<String> list) {
    list = new ArrayList<>();  // 不影响原变量
}
```

参数是**引用的副本**。

## 16.3 参数校验

```java
public void setAge(int age) {
    if (age < 0 || age > 150) {
        throw new IllegalArgumentException("age out of range");
    }
    this.age = age;
}
```

## 16.4 返回多个值

```java
public record DivMod(int quotient, int remainder) {}

static DivMod divmod(int a, int b) {
    return new DivMod(a / b, a % b);
}
```

或数组、Map。

## 16.5 Optional 返回值

```java
public Optional<String> findUser(String name) {
    return users.get(name);
}
```

## 16.6 不可变返回值

```java
public List<String> getItems() {
    return List.copyOf(items);  // 防止外部修改
}
```

## 16.7 陷阱

- 返回内部可变集合
- 参数被修改
- 返回 null

## 16.8 最佳实践

- 入参校验
- 返回不可变
- Optional 替代 null
- 方法短小

## 小结

- 只有值传递
- 引用传值可改对象
- 校验参数
- 用 Optional
