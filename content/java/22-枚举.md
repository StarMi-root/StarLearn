# 第 5 章 面向对象

# 22. 枚举

## 学习目标

- 掌握 enum 定义
- 学会枚举方法
- 理解 switch 表达式

## 22.1 基本用法

```java
public enum Color {
    RED, GREEN, BLUE
}

Color c = Color.RED;
int ordinal = c.ordinal();  // 0
String name = c.name();     // "RED"
```

## 22.2 带字段

```java
public enum Direction {
    N(0, 1), E(1, 0), S(0, -1), W(-1, 0);

    private final int dx, dy;

    Direction(int dx, int dy) {
        this.dx = dx;
        this.dy = dy;
    }

    public int deltaX() { return dx; }
    public int deltaY() { return dy; }
}
```

## 22.3 抽象方法

```java
public enum Operation {
    PLUS {
        public int apply(int a, int b) { return a + b; }
    },
    MULTIPLY {
        public int apply(int a, int b) { return a * b; }
    };

    public abstract int apply(int a, int b);
}
```

## 22.4 switch 表达式

```java
int result = switch (op) {
    case PLUS -> op.apply(2, 3);
    case MULTIPLY -> op.apply(2, 3);
};
```

## 22.5 遍历

```java
for (Direction d : Direction.values()) {
    System.out.println(d);
}
```

## 22.6 陷阱

- ordinal 不稳定
- 枚举作 Map 键
- 常量池

## 22.7 最佳实践

- 枚举表达有限集合
- switch 全覆盖
- 避免 ordinal

## 小结

- enum 常量
- 带字段构造器
- switch 表达式
- 抽象方法
