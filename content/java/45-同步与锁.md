# 第 11 章 并发

# 45. 同步与锁

## 学习目标

- 掌握 synchronized
- 学会 ReentrantLock
- 理解死锁

## 45.1 synchronized

```java
public synchronized void method() {
    // 对象锁
}
static synchronized void classMethod() {
    // 类锁
}
synchronized (lock) {
    // 显式锁对象
}
```

## 45.2 ReentrantLock

```java
Lock lock = new ReentrantLock();
lock.lock();
try {
    // critical section
} finally {
    lock.unlock();
}
```

## 45.3 条件变量

```java
Condition cond = lock.newCondition();
cond.await();
cond.signal();
```

## 45.4 死锁

```
线程 A 持有锁 1，等待锁 2
线程 B 持有锁 2，等待锁 1
→ 死锁
```

## 45.5 避免死锁

- 固定加锁顺序
- tryLock 超时
- 锁粒度小

## 45.6 陷阱

- 忘记 unlock
- 锁顺序
- 大锁

## 45.7 最佳实践

- 锁粒度小
- 读多写少用读锁
- tryLock

## 小结

- synchronized 简洁
- ReentrantLock 灵活
- 避免死锁
- 锁粒度小
