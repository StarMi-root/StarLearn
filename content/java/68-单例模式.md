# 第 19 章 设计模式

# 68. 单例模式

## 学习目标

- 掌握单例
- 学会线程安全
- 理解陷阱

## 68.1 饿汉式

```java
public class Singleton {
    private static final Singleton INSTANCE = new Singleton();
    private Singleton() { }
    public static Singleton getInstance() {
        return INSTANCE;
    }
}
```

## 68.2 懒汉 + 双重检查

```java
public class Singleton {
    private static volatile Singleton instance;

    public static Singleton getInstance() {
        if (instance == null) {
            synchronized (Singleton.class) {
                if (instance == null) {
                    instance = new Singleton();
                }
            }
        }
        return instance;
    }
}
```

## 68.3 枚举单例

```java
public enum Singleton {
    INSTANCE;
}
```

最简洁、防反射。

## 68.4 陷阱

- 反射攻击
- 序列化
- 子类

## 68.5 最佳实践

- 枚举优先
- volatile
- 私有构造

## 小结

- 饿汉简单
- 双重检查
- 枚举最佳
- 防反射
