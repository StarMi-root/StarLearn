# 第 2 章 控制流

# 8. 循环嵌套与常用模式

## 学习目标

- 掌握嵌套循环
- 学会常见遍历模式
- 避免重复代码

## 8.1 矩阵打印

```java
for (int i = 0; i < n; i++) {
    for (int j = 0; j < m; j++) {
        System.out.print(matrix[i][j] + " ");
    }
    System.out.println();
}
```

## 8.2 双层去重

```java
for (int i = 0; i < n; i++) {
    for (int j = i + 1; j < n; j++) {
        // 处理 (i, j) 对
    }
}
```

## 8.3 查找

```java
boolean found = false;
for (int x : list) {
    if (x == target) {
        found = true;
        break;
    }
}
```

## 8.4 收集结果

```java
List<Integer> squares = new ArrayList<>();
for (int i = 0; i < n; i++) {
    squares.add(i * i);
}
```

或 Stream（见第 37 节）：

```java
List<Integer> squares = IntStream.range(0, n)
    .map(i -> i * i)
    .boxed()
    .toList();
```

## 8.5 计数器

```java
Map<String, Integer> counts = new HashMap<>();
for (String word : words) {
    counts.merge(word, 1, Integer::sum);
}
```

## 8.6 提前终止

```java
for (int i = 0; i < n; i++) {
    if (condition) {
        handle(i);
        break;
    }
}
```

## 8.7 带索引遍历

```java
List<String> items = ...;
for (int i = 0; i < items.size(); i++) {
    String s = items.get(i);
    // 用 i 和 s
}
```

或增强 for + 手动计数。

## 8.8 陷阱

- 嵌套循环性能
- 忘记 break
- 修改集合导致 ConcurrentModificationException

## 8.9 最佳实践

- 提取子循环为方法
- 用标签跳出多层
- 避免 O(n²) 不必要

## 8.10 常见复杂度

| 模式 | 复杂度 |
|------|--------|
| 单层 | O(n) |
| 双层 | O(n²) |
| 分治 | O(n log n) |
| 哈希查找 | O(n) |

## 小结

- 嵌套保持简洁
- 收集结果用 List/Map
- 用 Stream 简化
