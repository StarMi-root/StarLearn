# 70. 观察者模式

## 学习目标

- 掌握观察者
- 学会事件发布
- 理解应用场景

## 70.1 基本结构

```java
public interface Observer {
    void update(Event e);
}

public class Subject {
    private final List<Observer> observers = new ArrayList<>();

    public void attach(Observer o) {
        observers.add(o);
    }

    public void notifyObservers(Event e) {
        observers.forEach(o -> o.update(e));
    }
}
```
