# 第 2 章 控制流

# 6. 条件语句

## 学习目标

- 掌握 if/else
- 学会 switch 语句与表达式
- 避免嵌套过深

## 6.1 if / else

```java
int score = 85;
if (score >= 90) {
    System.out.println("A");
} else if (score >= 80) {
    System.out.println("B");
} else if (score >= 70) {
    System.out.println("C");
} else {
    System.out.println("D");
}
```

## 6.2 switch 语句

```java
switch (day) {
    case "Mon":
    case "Tue":
        System.out.println("work");
        break;
    case "Sat":
    case "Sun":
        System.out.println("rest");
        break;
    default:
        System.out.println("unknown");
}
```

`break` 防止穿透。

## 6.3 switch 表达式（Java 14+）

```java
String label = switch (day) {
    case "Mon", "Tue", "Wed", "Thu", "Fri" -> "work";
    case "Sat", "Sun" -> "rest";
    default -> "unknown";
};
```

`->` 箭头语法，自动 break。

## 6.4 switch 与枚举

```java
enum Status { ACTIVE, INACTIVE }

switch (status) {
    case ACTIVE -> log.info("active");
    case INACTIVE -> log.info("inactive");
}
```

## 6.5 嵌套与扁平化

```java
// 差
if (a) {
    if (b) {
        if (c) { ... }
    }
}

// 好
if (a && b && c) { ... }
```

## 6.6 守卫子句

```java
void process(User u) {
    if (u == null) return;
    if (u.banned()) return;
    // 主逻辑
}
```

## 6.7 三元

```java
int abs = x < 0 ? -x : x;
```

## 6.8 陷阱

- switch 缺 break 穿透
- 浮点不用 switch
- `==` 比较对象应使用 `equals`

## 6.9 最佳实践

- 用 switch 表达式
- 枚举 + switch 全覆盖
- 守卫子句扁平化

## 小结

- if 链用 else if
- switch 表达式现代
- 嵌套过深就重构
