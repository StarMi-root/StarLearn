# 第 9 章 泛型

# 35. 通配符与边界

## 学习目标

- 掌握通配符
- 学会上界下界
- 理解 producer/consumer

## 35.1 无界通配符

```java
void printList(List<?> list) {
    for (Object o : list) {
        System.out.println(o);
    }
}
```

## 35.2 上界（? extends）

```java
int sum(List<? extends Number> list) {
    int total = 0;
    for (Number n : list) total += n.intValue();
    return total;
}
```

读多写少用 extends。

## 35.3 下界（? super）

```java
void addAll(List<? super Integer> list) {
    list.add(1);  // 只能添加 Integer
}
```

写多用 super。

## 35.4 PECS 原则

```
Producer Extends, Consumer Super
```

## 35.5 通配符方法

```java
static <T> T findFirst(List<? extends T> list, Predicate<T> p) {
    return list.stream().filter(p).findFirst().orElse(null);
}
```

## 35.6 陷阱

- 通配符不能 new
- 不能 cast
- 类型参数不同

## 35.7 最佳实践

- 读用 extends
- 写用 super
- 避免无界

## 35.8 实际场景

- 集合互转
- 算法接口
- 回调

## 小结

- ? extends 读
- ? super 写
- PECS
- 通配符不能 new
