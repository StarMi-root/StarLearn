# 第 12 章 JVM 与性能

# 48. GC 调优入门

## 学习目标

- 理解 GC 类型
- 学会 G1、ZGC
- 掌握监控

## 48.1 GC 类型

- Serial
- Parallel
- CMS
- G1
- ZGC
- Shenandoah

## 48.2 G1（默认）

```bash
java -XX:+UseG1GC -XX:MaxGCPauseMillis=200
```

- 分区
- 可预测停顿

## 48.3 ZGC

```bash
java -XX:+UseZGC -XX:MaxZGCHeapSize=32g
```

- 亚毫秒停顿
- 大堆友好

## 48.4 监控

```bash
jstat -gcutil pid 1000
jcmd pid GC.heap_info
```

## 48.5 日志

```bash
-Xlog:gc*:file=gc.log:time,uptime,level,tags
```

## 48.6 调优

- 堆大小
- 停顿目标
- 分代比例

## 48.7 陷阱

- 频繁 Full GC
- 堆过大
- 参数不当

## 48.8 最佳实践

- G1 默认
- ZGC 大堆
- 监控日志
- 基准测试

## 小结

- G1 默认
- ZGC 低停顿
- 日志监控
- 调优
