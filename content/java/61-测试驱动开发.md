# 第 16 章 测试

# 61. 测试驱动开发

## 学习目标

- 理解 TDD
- 学会红绿重构
- 掌握测试设计

## 61.1 流程

1. **红**：写失败测试
2. **绿**：写最少代码通过
3. **重构**：改进代码

## 61.2 示例

### 需求：计算折扣

#### 红

```java
@Test
void testDiscount() {
    assertEquals(90, Pricing.discount(100, 0.1));
}
```

#### 绿

```java
public static int discount(int price, double discount) {
    return (int) (price * (1 - discount));
}
```

#### 重构

```java
public static int discount(int price, double discount) {
    if (discount < 0 || discount > 1) {
        throw new IllegalArgumentException();
    }
    return (int) (price * (1 - discount));
}
```
