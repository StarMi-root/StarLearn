# 第 3 章 数据结构

# 9. 字符串

## 学习目标

- 理解 String 不可变
- 学会 StringBuilder
- 掌握常用方法

## 9.1 不可变性

```java
String s = "hello";
s = s + " world";  // 新对象
```

String 对象创建后不可修改。

## 9.2 创建

```java
String s1 = "abc";
String s2 = new String("abc");
String s3 = "a" + "b" + "c";  // 编译期优化
```

`==` 比较身份，`.equals()` 比较内容。

## 9.3 常用方法

```java
s.length()
s.charAt(i)
s.substring(i, j)
s.indexOf("x")
s.contains("x")
s.startsWith("x")
s.endsWith("x")
s.replace("a", "b")
s.replaceAll("\\d", "#")
s.split(",")
s.trim()
s.toUpperCase()
s.toLowerCase()
```

## 9.4 StringBuilder

```java
StringBuilder sb = new StringBuilder();
sb.append("a").append('1').append(2);
sb.insert(0, "x");
sb.deleteCharAt(0);
sb.reverse();
String result = sb.toString();
```

大量拼接用 StringBuilder，避免 O(n²)。

## 9.5 String vs StringBuilder

| 特性 | String | StringBuilder |
|------|--------|---------------|
| 可变 | 否 | 是 |
| 线程安全 | 是（不可变） | 否 |
| 性能（拼接） | 差 | 好 |

## 9.6 StringBuffer

线程安全，同步方法，性能略差。

## 9.7 字符串驻留

```java
String a = "abc";
String b = "abc";
a == b  // true（驻留池）

String c = new String("abc");
a == c  // false
```

## 9.8 编码

```java
byte[] bytes = "你好".getBytes("UTF-8");
String s = new String(bytes, "UTF-8");
```

## 9.9 陷阱

- 循环中 `s += x` 性能差
- `==` 比较 String
- 忘记指定编码

## 9.10 最佳实践

- 拼接用 StringBuilder
- 比较用 equals
- 显式编码

## 小结

- String 不可变
- 拼接用 StringBuilder
- 驻留池小心
- 显式 UTF-8
