# 第 5 章 面向对象

# 19. 继承与多态

## 学习目标

- 理解 extends
- 学会 override
- 掌握 super

## 19.1 继承

```java
public class Animal {
    public String name;

    public void speak() {
        System.out.println("...");
    }
}

public class Dog extends Animal {
    public void speak() {
        System.out.println("woof");
    }
}
```

## 19.2 单继承

Java 类只能单继承，接口可多实现。

## 19.3 super

```java
public class Dog extends Animal {
    public Dog(String name) {
        super(name);  // 调用父构造器
    }

    public void speak() {
        super.speak();  // 调用父方法
    }
}
```

## 19.4 override 与 @Override

```java
@Override
public int hashCode() {
    return 42;
}
```

`@Override` 编译期检查。

## 19.5 多态

```java
List<Animal> animals = List.of(new Dog(), new Cat());
for (Animal a : animals) {
    a.speak();  // 动态分发
}
```

## 19.6 类型转换

```java
Animal a = new Dog("Rex");
Dog d = (Dog) a;  // 向下转型
```

`instanceof` 检查：

```java
if (a instanceof Dog d) {
    d.speak();
}
```

Java 16+ 模式匹配。

## 19.7 方法查找

- 编译时：静态方法按引用类型
- 运行时：实例方法按实际类型

## 19.8 陷阱

- 父类引用指向子类
- 向下转型失败
- 循环继承

## 19.9 设计原则

- 里氏替换
- 优先组合
- 继承表达"是"

## 19.10 最佳实践

- 类短小
- 多用组合
- 抽象类/接口

## 小结

- 单继承
- super 调用父
- @Override 检查
- 多态运行时
