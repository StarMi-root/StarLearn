# 第 19 章 设计模式

# 71. 策略模式

## 学习目标

- 掌握策略
- 学会函数式策略
- 理解场景

## 71.1 接口

```java
public interface PaymentStrategy {
    void pay(int amount);
}

public class CreditCard implements PaymentStrategy {
    public void pay(int amount) {
        System.out.println("pay " + amount + " by card");
    }
}
```

## 71.2 上下文

```java
public class Order {
    private PaymentStrategy strategy;

    public void setStrategy(PaymentStrategy s) {
        this.strategy = s;
    }

    public void pay(int amount) {
        strategy.pay(amount);
    }
}
```

## 71.3 函数式

```java
public interface Strategy<T, R> {
    R apply(T input);
}

Strategy<String, Integer> len = String::length;
len.apply("hello");  // 5
```

## 71.4 陷阱

- 策略过多
- 状态共享
- 复杂选择

## 71.5 最佳实践

- 函数式策略
- 策略工厂
- 简单选择
