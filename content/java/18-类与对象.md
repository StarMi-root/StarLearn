# 第 5 章 面向对象

# 18. 类与对象

## 学习目标

- 掌握类定义
- 学会构造器
- 理解字段与访问

## 18.1 基本语法

```java
public class Dog {
    private String name;
    private int age;

    public Dog(String name, int age) {
        this.name = name;
        this.age = age;
    }

    public void bark() {
        System.out.println(name + " says woof");
    }

    public static void main(String[] args) {
        Dog d = new Dog("Rex", 5);
        d.bark();
    }
}
```

## 18.2 构造器

```java
public class Point {
    private final double x, y;

    public Point(double x, double y) {
        this.x = x;
        this.y = y;
    }

    public Point() {
        this(0, 0);  // 委托
    }
}
```

## 18.3 实例 vs 类成员

```java
class MyClass {
    int instanceVar = 1;       // 实例
    static int classVar = 2;   // 类
}
```

## 18.4 访问控制

```java
private    // 类内
protected  // 包内 + 子类
public     // 所有
default    // 包内
```

## 18.5 this 关键字

```java
public MyClass copy() {
    return new MyClass(this.field);
}
```

## 18.6 初始化块

```java
class MyClass {
    {
        System.out.println("instance init");
    }
    static {
        System.out.println("static init");
    }
}
```

## 18.7 record（Java 16+）

```java
public record Point(double x, double y) {
    public double distance() {
        return Math.sqrt(x * x + y * y);
    }
}
```

自动生成构造器、getter、equals、hashCode、toString。

## 18.8 陷阱

- 字段默认 null/0
- 可变集合共享
- 缺少 final

## 18.9 最佳实践

- final 字段
- 构造器校验
- 私有字段 + getter

## 小结

- 构造器 this 委托
- record 简化数据类
- 访问控制严格
- final 优先
