# 第 11 章 并发

# 44. 虚拟线程

## 学习目标

- 理解 Java 21+ Loom
- 学会虚拟线程
- 理解优势与限制

## 44.1 创建

```java
Thread v = Thread.ofVirtual().start(() -> {
    System.out.println("virtual thread");
});
```

## 44.2 线程池

```java
try (var pool = Executors.newVirtualThreadPerTaskExecutor()) {
    pool.submit(() -> {
        // I/O 密集
    });
}
```

## 44.3 优势

- 轻量（KB 级）
- 百万级并发
- I/O 友好

## 44.4 限制

- CPU 密集无优势
- 同步阻塞仍阻塞载体
- 不适合计算密集

## 44.5 适用场景

- Web 服务器
- I/O 密集
- 大量连接

## 44.6 陷阱

- 同步锁
- 内存分配
- 载体线程耗尽

## 44.7 最佳实践

- I/O 密集用
- 避免同步阻塞
- 监控

## 小结

- Java 21+
- 轻量级
- I/O 友好
- 百万并发
