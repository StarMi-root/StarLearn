# 第 10 章 Stream 与函数式

# 40. 函数式接口

## 学习目标

- 掌握内置函数式接口
- 学会自定义
- 理解组合

## 40.1 Predicate

```java
Predicate<String> isLong = s -> s.length() > 5;
Predicate<String> isVowel = s -> "aeiou".contains(s);

isLong.and(isVowel);  // 组合
isLong.negate();      // 否定
```

## 40.2 Function

```java
Function<String, Integer> len = String::length;
Function<Integer, Integer> square = x -> x * x;

Function<String, Integer> composed = len.andThen(square);
```

## 40.3 Consumer

```java
Consumer<String> printer = System.out::println;
printer.accept("hello");
```

## 40.4 Supplier

```java
Supplier<List<String>> factory = ArrayList::new;
Supplier<Double> random = Math::random;
```

## 40.5 UnaryOperator / BinaryOperator

```java
UnaryOperator<Integer> inc = x -> x + 1;
BinaryOperator<Integer> sum = Integer::sum;
```

## 40.6 自定义

```java
@FunctionalInterface
public interface TriFunction<A, B, C, R> {
    R apply(A a, B b, C c);
}
```

## 40.7 组合

```java
Predicate<String> p = p1.and(p2).or(p3);
Function<A, B> f = f1.andThen(f2);
```

## 40.8 陷阱

- 复杂 Lambda 提取方法
- 嵌套过深
- 副作用

## 40.9 最佳实践

- 单行 Lambda
- 方法引用
- 组合简单

## 小结

- 四大接口
- 组合强大
- 简洁优先
