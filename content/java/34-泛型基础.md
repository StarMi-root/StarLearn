# 第 9 章 泛型

# 34. 泛型基础

## 学习目标

- 掌握泛型类与方法
- 理解类型擦除
- 学会泛型约束

## 34.1 泛型类

```java
public class Box<T> {
    private T item;

    public void set(T item) { this.item = item; }
    public T get() { return item; }
}

Box<String> b = new Box<>();
b.set("hello");
```

## 34.2 泛型方法

```java
public static <T> List<T> reverse(List<T> list) {
    List<T> result = new ArrayList<>(list);
    Collections.reverse(result);
    return result;
}
```

## 34.3 类型参数约束

```java
public class Max<T extends Comparable<T>> {
    public T max(T a, T b) {
        return a.compareTo(b) >= 0 ? a : b;
    }
}
```

## 34.4 多参数

```java
public class Pair<K, V> {
    private K key;
    private V value;
}
```

## 34.5 类型擦除

Java 泛型在运行时擦除：

```java
List<String> list = ...;
Object o = list;  // 实际是 List
```

不能 `new T()`、`T.class`。

## 34.6 陷阱

```java
// 不能
T x = new T();
T[] arr = new T[10];
```

## 34.7 原生类型

```java
List list = new ArrayList();  // 原始类型，警告
```

## 34.8 最佳实践

- 泛型替代 Object
- 约束最小
- 避免原生类型

## 小结

- 类型参数 <T>
- 约束 extends
- 类型擦除
- 避免原生
