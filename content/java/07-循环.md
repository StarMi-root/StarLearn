# 第 2 章 控制流

# 7. 循环

## 学习目标

- 掌握 for / while / do-while
- 学会增强 for
- 理解 break 与 continue

## 7.1 for 循环

```java
for (int i = 0; i < 10; i++) {
    System.out.println(i);
}
```

## 7.2 while 循环

```java
int i = 0;
while (i < 10) {
    i++;
}
```

## 7.3 do-while

```java
do {
    // 至少执行一次
} while (condition);
```

## 7.4 增强 for（for-each）

```java
int[] arr = {1, 2, 3};
for (int x : arr) {
    System.out.println(x);
}

for (String s : list) { ... }
```

不能修改集合结构，不能访问索引。

## 7.5 break 与 continue

```java
for (int i = 0; i < 10; i++) {
    if (i % 2 == 0) continue;
    if (i >= 7) break;
    System.out.println(i);
}
// 1 3 5
```

## 7.6 标签

```java
outer:
for (int i = 0; i < 10; i++) {
    for (int j = 0; j < 10; j++) {
        if (condition) break outer;
    }
}
```

## 7.7 嵌套

```java
for (int i = 0; i < n; i++) {
    for (int j = 0; j < m; j++) {
        // ...
    }
}
```

## 7.8 陷阱

- `i++` 与 `i = i + 1` 不同
- 增强 for 中修改集合
- 死循环

## 7.9 最佳实践

- 优先 for
- 避免嵌套过深
- 用 break 标签跳出多层

## 7.10 生成器循环

```java
for (var it = list.iterator(); it.hasNext(); ) {
    var x = it.next();
    if (shouldRemove) it.remove();
}
```

## 小结

- for 最常用
- for-each 简洁
- 标签 break 跳多层
- 避免死循环
