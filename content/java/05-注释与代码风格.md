# 第 1 章 入门基础

# 5. 注释与代码风格

## 学习目标

- 掌握 Java 注释
- 了解命名规范
- 使用 Javadoc

## 5.1 注释类型

```java
// 单行注释

/* 多行
   注释 */

/**
 * Javadoc 注释
 * 生成 API 文档
 */
```

## 5.2 Javadoc 标签

```java
/**
 * 计算圆的面积。
 *
 * @param radius 半径，必须为正数
 * @return 圆的面积
 * @throws IllegalArgumentException 当半径为负时
 */
public double area(double radius) {
    if (radius < 0) throw new IllegalArgumentException();
    return Math.PI * radius * radius;
}
```

## 5.3 命名规范

| 类型 | 风格 | 示例 |
|------|------|------|
| 类 | 大驼峰 | `MyClass`, `UserService` |
| 方法 | 小驼峰 | `myMethod()`, `getUser()` |
| 变量 | 小驼峰 | `myVar`, `userCount` |
| 常量 | 全大写下划线 | `MAX_SIZE`, `PI` |
| 包 | 全小写 | `com.example.myapp` |
| 泛型参数 | 单字母 | `T`, `E`, `K`, `V` |

## 5.4 格式

- 4 空格缩进
- 行宽 100~120 字符
- 左花括号不换行（K&R）

```java
public class Foo {
    public void bar() {
        if (x > 0) {
            // ...
        }
    }
}
```

## 5.5 import 顺序

```java
import java.util.*;
import com.example.*;
import static org.junit.Assert.*;
```

避免 `import *`，除非必要。

## 5.6 方法

- 单一职责
- 短函数（< 20 行）
- 参数不超过 5 个

## 5.7 工具

- **Checkstyle**：风格检查
- **SpotBugs**：bug 检测
- **PMD**：静态分析
- **IntelliJ 格式化**：一键整理

## 5.8 陷阱

- 注释与代码脱节
- 命名不一致
- 魔法数字

## 5.9 最佳实践

- 方法加 Javadoc
- 常量提取命名
- 避免行尾空格
- 用工具自动格式化

## 小结

- 三种注释
- 命名规范严格
- Javadoc 生成文档
- 工具辅助
