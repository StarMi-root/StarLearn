# 第 6 章 包与模块化

# 25. 访问修饰符

## 学习目标

- 掌握四种访问级别
- 理解作用域
- 学会封装

## 25.1 四种修饰符

| 修饰符 | 类内 | 包内 | 子类 | 任意 |
|--------|------|------|------|------|
| private | ✓ | | | |
| default | ✓ | ✓ | | |
| protected | ✓ | ✓ | ✓ | |
| public | ✓ | ✓ | ✓ | ✓ |

## 25.2 private

```java
public class MyClass {
    private int secret;
}
```

仅类内可见。

## 25.3 default

```java
class MyClass {
    int internal;  // 包内可见
}
```

## 25.4 protected

```java
public class Parent {
    protected int shared;
}
```

子类 + 包内可见。

## 25.5 public

```java
public class Api {
    public void doWork() { }
}
```

## 25.6 嵌套类访问

```java
public class Outer {
    private int x = 1;

    public static class Inner {
        public void use() {
            // 不能访问 Outer.x（不同实例）
        }
    }

    public class Inner2 {
        public void use() {
            System.out.println(x);  // 可以
        }
    }
}
```

## 25.7 封装原则

- 字段 private
- getter / setter
- 最小可见性

## 25.8 陷阱

- public 过用
- 嵌套类访问
- 包私有误用

## 25.9 最佳实践

- 默认 private
- 需要时再放宽
- 避免 protected 滥用

## 小结

- 最小可见性
- private 优先
- protected 子类
- 封装
