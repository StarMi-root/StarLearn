# 第 1 章 入门基础

# 1. 环境与安装

## 学习目标

- 安装 JDK
- 学会使用 javac 编译与 java 运行
- 运行第一个 Java 程序

## 1.1 检查是否已安装

```bash
java -version
javac -version
```

若输出版本号（如 `java version "17.0.x"`）则已安装。

## 1.2 安装 JDK

### macOS / Linux

- **macOS**：`brew install openjdk` 或 `brew install --cask temurin`
- **Ubuntu**：`sudo apt install openjdk-17-jdk`
- **Arch**：`sudo pacman -S jdk17`

### Windows

- 访问 https://adoptium.net 下载 Temurin JDK
- 安装后设置 `JAVA_HOME` 与 `PATH`

## 1.3 设置环境变量

```bash
# Linux / macOS
export JAVA_HOME=/usr/lib/jvm/java-17
export PATH=$JAVA_HOME/bin:$PATH
```

验证：

```bash
which javac
which java
```

## 1.4 第一个程序

创建 `Hello.java`：

```java
public class Hello {
    public static void main(String[] args) {
        System.out.println("Hello, World!");
    }
}
```

编译与运行：

```bash
javac Hello.java
java Hello
```

## 1.5 类名与文件名

- 公共类名必须与文件名一致
- 一个文件可以多个类，但只能一个 public 类

## 1.6 推荐 IDE

- **IntelliJ IDEA**（社区版免费）
- **Eclipse**
- **VS Code** + Java 扩展

## 1.7 包结构

生产代码建议放在包内：

```
src/
  com/example/hello/
    Hello.java
```

对应 `package com.example.hello;` 声明。

## 1.8 小结

- JDK = 编译器 + 运行时
- `javac` 编译，`java` 运行
- 类名必须匹配文件名
- 使用 IDE 提升效率
