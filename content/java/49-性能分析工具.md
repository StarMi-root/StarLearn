## 49.3 JMH

```java
@Benchmark
public int benchmark() { ... }

@Fork(1)
@WarmupIterations(3)
@MeasurementIterations(5)
public class MyBenchmark {
    public static void main(String[] args) throws Exception {
        Options opt = new Options().include(MyBenchmark.class).build();
        new Runner(opt).run();
    }
}
```
