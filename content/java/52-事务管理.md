# 52. 事务管理

## 学习目标

- 理解 ACID
- 学会事务边界
- 掌握隔离级别

## 52.1 ACID

- **A**tomicity：原子性
- **C**onsistency：一致性
- **I**solation：隔离性
- **D**urability：持久性

## 52.2 JDBC 事务

```java
conn.setAutoCommit(false);
try {
    // 多个操作
    conn.commit();
} catch (Exception e) {
    conn.rollback();
    throw e;
}
```

## 52.3 JPA 事务

```java
@Transactional
public void transfer(long from, long to, long amount) {
    em.find(Account.class, from).withdraw(amount);
    em.find(Account.class, to).deposit(amount);
}
```

## 52.4 隔离级别

```
READ UNCOMMITTED
READ COMMITTED
REPEATABLE READ
SERIALIZABLE
```

```java
conn.setTransactionIsolation(Connection.TRANSACTION_READ_COMMITTED);
```
