# 移动开发学习地图：Android、Flutter 与 Swift

移动开发要先决定路线：原生 Android/iOS，还是 Flutter/Ionic 跨平台。原生适合深度系统能力和单一平台体验；跨平台适合小团队快速覆盖多端。无论哪条路线，生命周期、状态管理、网络和发布都绕不过去。

![移动开发图标（Simple Icons CC0 / Lucide ISC）](/static/img/icons/si-android.svg)

:::tip 先选一条主线
不要同时开五门课。先按下面的顺序完成一个最小项目，再把目录里的其他主题当作按需查阅的工具书。
:::

## 推荐学习顺序

1. **Kotlin 与 Android 基础**：掌握 Activity、布局、列表、导航、权限和 Gradle。
2. **Flutter 与 Dart**：用 Widget 组合界面，理解状态、路由和平台通道。
3. **Swift 与 iOS**：理解 Swift 语法、SwiftUI/UIKit 基础与 Apple 发布流程。
4. **Ionic 与 jQuery Mobile**：了解 WebView 混合应用的能力边界，适合内容型和内部工具。
5. **完成一个可安装应用**：从接口取数、处理离线与错误，再走完签名、打包和发布。

## 学完后的检查点

- 能解释 Android Activity 与 Fragment 生命周期。
- 能说明 Flutter 热重载和平台通道的用途。
- 能完成一次真机调试与安装包构建。

:::note 学习建议
每学完一个主题，至少留下三样东西：一段可运行的代码、一条自己的解释、一个能复现的踩坑记录。把它们放进笔记或项目仓库，比“看过”更能证明掌握。
:::
