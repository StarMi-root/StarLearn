# 网站建设学习地图：从域名到上线运营

建站不是把 HTML 上传就结束了。一个可运营的网站还需要域名解析、HTTPS、主机监控、备份、性能优化、搜索引擎可发现性和无障碍。按“能访问 → 能稳定运行 → 能被找到 → 能持续改进”推进。

![网站建设图标（Simple Icons CC0 / Lucide ISC）](/static/img/icons/lu-globe.svg)

:::tip 先选一条主线
不要同时开五门课。先按下面的顺序完成一个最小项目，再把目录里的其他主题当作按需查阅的工具书。
:::

## 推荐学习顺序

1. **网站建设指南**：确定信息架构、技术栈、域名和主机，画出上线检查表。
2. **浏览器信息**：理解内核差异、兼容性边界和开发者工具。
3. **网站主机教程**：配置 DNS、HTTPS、防火墙、备份和日志。
4. **网站品质**：检查性能、SEO、可访问性、安全头与内容质量。
5. **持续运营**：接入统计与监控，定期更新内容并验证备份可恢复。

## 学完后的检查点

- 能独立把静态站点部署到 Linux 或 GitHub Pages。
- 能解释 DNS A/CNAME 记录和 HTTPS 证书签发流程。
- 能用 Lighthouse 找出一项可改进的性能问题。

:::note 学习建议
每学完一个主题，至少留下三样东西：一段可运行的代码、一条自己的解释、一个能复现的踩坑记录。把它们放进笔记或项目仓库，比“看过”更能证明掌握。
