# 操作系统原理

操作系统管理 CPU、内存、设备和文件，为应用提供稳定、隔离的执行环境。服务器排障与性能优化，最终都会落到这些机制上。

## 内核与用户态

- **内核态**：可执行特权指令，访问全部硬件。
- **用户态**：应用运行在受限环境，通过系统调用请求内核服务。

系统调用示例：`read`、`write`、`open`、`fork`、`execve`、`mmap`、`socket`。频繁系统调用有开销，但不要为了“减少调用”而牺牲正确性。

## 进程与线程

**进程**是资源分配单位，拥有独立虚拟地址空间、文件描述符和环境变量。**线程**是调度单位，同一进程内线程共享地址空间。

```text
进程
├── 代码段
├── 数据段
├── 堆
├── 文件描述符表
└── 线程 1..N
    ├── 栈
    ├── 寄存器
    └── 线程本地存储
```

线程共享内存带来通信便利，也带来数据竞争。需要锁、原子操作或无共享设计。

## 上下文切换

CPU 从一个线程切换到另一个线程时，需要保存/恢复寄存器、栈指针和调度状态。频繁切换会消耗 CPU，并破坏缓存局部性。

```bash
vmstat 1
pidstat -w -p <pid> 1
```

线程数不是越多越好。I/O 密集型可适当增加，CPU 密集型通常接近核数。

## 调度

调度器决定下一个运行的线程。目标包括公平、低延迟、高吞吐。Linux 常用 CFS/EEVDF 等调度策略，并提供实时调度类。

优先级过高可能饿死其他任务。生产环境不要随意使用实时优先级。

## 虚拟内存

每个进程看到独立、连续的地址空间。MMU 通过页表把虚拟地址翻译成物理地址。

```text
虚拟地址 → 页表 → 物理页框
         ↳ 未命中 → 缺页异常 → 从磁盘/交换区加载
```

好处：

- 隔离进程，防止越界访问。
- 按需分页，节省物理内存。
- 共享库映射，减少重复加载。
- 支持 Swap 与内存映射文件。

代价：页表开销、TLB 未命中、缺页延迟。

## 内存管理

- **栈**：函数调用、局部变量，自动回收。
- **堆**：动态分配，需 GC 或手动释放。
- **页缓存**：内核缓存文件数据，提升读写性能。
- **Swap**：内存不足时换出冷页，延迟显著增加。

```bash
free -h
cat /proc/meminfo
cat /proc/<pid>/status
```

`available` 比 `free` 更能反映可用内存。Linux 会积极使用空闲内存做缓存，这是正常的。

## 文件系统

文件系统把块设备组织成目录、文件和元数据。常见：

- ext4：通用、稳定。
- XFS：大文件与高并发。
- Btrfs/ZFS：快照、校验、子卷。
- overlayfs：容器镜像分层。

inode 保存元数据，目录项把名字映射到 inode。硬链接共享 inode，软链接保存路径。

## 系统调用与库

```c
ssize_t n = read(fd, buf, size);
if (n < 0) {
    perror("read");
}
```

应用通常通过 libc/运行时调用系统调用。`strace` 可以观察进程的系统调用：

```bash
strace -f -e trace=file,network ./app
```

## 并发与同步

- 互斥锁：保护临界区。
- 读写锁：读多写少。
- 信号量：限制并发数量。
- 条件变量：等待状态变化。
- 原子操作：无锁计数与标志。
- 无共享/消息传递：减少锁竞争。

死锁需要同时满足互斥、持有并等待、不可抢占、循环等待。破坏任一条件即可预防。

## 容器与命名空间

容器不是轻量虚拟机，而是利用 Linux 的：

- **namespace**：隔离进程、网络、挂载、用户等视图。
- **cgroups**：限制 CPU、内存、I/O。
- **联合文件系统**：分层镜像。

容器共享宿主内核，因此隔离性弱于虚拟机。运行不可信代码时应使用更强的沙箱或 VM。

## 操作系统排障

```bash
top
vmstat 1
iostat -xz 1
ss -tulpn
journalctl -xe
dmesg -T | tail
```

先判断瓶颈：CPU、内存、磁盘 I/O、网络还是锁。不要看到负载高就直接重启。

:::tip 从机制到现象
进程、虚拟内存、页缓存、文件描述符和 cgroups 是解释大多数服务器现象的基础。遇到问题先问：哪个资源被谁占用，为什么没有释放？
:::

## 小练习

1. 用 `ps`、`/proc` 查看一个进程的线程、内存与文件描述符。
2. 用 `strace` 跟踪一个命令的文件访问。
3. 解释容器与虚拟机在隔离层面的差异。
