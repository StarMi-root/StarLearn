# 第 1 章 入门基础

# 5. 注释与代码风格

## 学习目标

- 学会写注释
- 理解 PEP 8 核心规则
- 掌握命名约定

## 5.1 注释

### 单行注释

```python
x = 10  # 这是单行注释
```

### 多行注释

用三引号写多行文档：

```python
"""
这是多行说明。
通常用作模块、类、函数的 docstring。
"""
```

注意：三引号字符串**不是**注释，是字符串字面量。

## 5.2 PEP 8 核心规则

### 缩进

- 4 个空格（不要混用 tab）

### 行宽

- 建议不超过 79 字符

### 空行

- 函数之间：2 个空行
- 类内方法之间：1 个空行
- 逻辑块之间：1 个空行

### 导入

```python
# 顺序：标准库 → 第三方库 → 本地模块，组间空行
import os
import sys

import requests
import numpy as np

from mypackage import mymodule
```

不要一行导入多个模块：

```python
# 差
import os, sys

# 好
import os
import sys
```

## 5.3 命名约定

| 类型 | 风格 | 示例 |
|------|------|------|
| 模块 | 小写下划线 | `my_module.py` |
| 函数 / 变量 | 小写下划线 | `my_function`, `user_name` |
| 类 | 大驼峰 | `MyClass`, `UserService` |
| 常量 | 全大写下划线 | `MAX_SIZE`, `PI` |
| 私有 | 前缀下划线 | `_internal_use` |
| 避免命名遮蔽 | 不用 `is`, `as`, `in` 等关键字 | — |

## 5.4 常用工具

- **ruff**：快速 linter + formatter（推荐）
- **black**：自动格式化
- **pylint**：更严格的代码检查
- **mypy**：静态类型检查

## 5.5 写好 docstring

```python
def calculate_area(radius: float) -> float:
    """计算圆的面积。

    Args:
        radius: 圆的半径，必须非负。

    Returns:
        圆的面积。

    Raises:
        ValueError: 当半径为负数时。
    """
    if radius < 0:
        raise ValueError("半径不能为负")
    return 3.14159 * radius ** 2
```

## 小结

- 4 空格缩进
- 小写下划线命名
- 三引号字符串是 docstring
- 用 ruff/black 保持风格一致
