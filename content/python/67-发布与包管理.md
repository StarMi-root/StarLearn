# 67. 发布与包管理

## 学习目标

- 掌握 pyproject.toml
- 学会构建与发布
- 理解版本号

## 67.1 pyproject.toml

```toml
[build-system]
requires = ["setuptools>=61.0", "wheel"]
build-backend = "setuptools.build_meta"

[project]
name = "mypackage"
version = "1.0.0"
description = "A great package"
readme = "README.md"
requires-python = ">=3.8"
dependencies = [
    "requests>=2.20",
    "numpy"
]

[project.optional-dependencies]
dev = ["pytest", "ruff"]
```

## 67.2 构建

```bash
pip install build
python -m build
# 生成 dist/ 目录
```

## 67.3 安装

```bash
pip install mypackage-1.0.0-py3-none-any.whl
# 或开发模式
pip install -e .
```

## 67.4 发布到 PyPI

```bash
pip install twine

# 测试
twine upload --repository-url https://test.pypi.org/legacy/ dist/*

# 正式
twine upload dist/*
```

## 67.5 版本号（SemVer）

```
MAJOR.MINOR.PATCH
  |     |     |
  |     |     + 向后兼容的修复
  |     + 新功能，向后兼容
  + 不兼容变更
```

## 67.6 发布流程

1. 修改版本号
2. 更新 CHANGELOG
3. 打 tag：`git tag v1.0.0`
4. 构建：`python -m build`
5. 上传：`twine upload`
6. 测试安装

## 67.11 CI 发布

```yaml
# .github/workflows/publish.yml
on:
  release:
    types: [published]
jobs:
  publish:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - run: python -m build
      - run: twine upload dist/*
        env:
          TWINE_PASSWORD: ${{ secrets.PYPI_PASSWORD }}
```
