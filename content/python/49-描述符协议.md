# 第 9 章 进阶特性

# 49. 描述符协议

## 学习目标

- 理解描述符
- 实现 property 原理
- 掌握自定义描述符

## 49.1 什么是描述符

定义 `__get__`、`__set__`、`__delete__` 之一的对象。

```python
class Descriptor:
    def __get__(self, instance, owner):
        return instance.__dict__[self.name]

    def __set__(self, instance, value):
        instance.__dict__[self.name] = value

    def __set_name__(self, owner, name):
        self.name = name
```

## 49.2 非数据描述符

只有 `__get__`（或没有 `__set__`）：

```python
class Cached:
    def __init__(self, func):
        self.func = func

    def __get__(self, instance, owner):
        if instance is None:
            return self
        result = self.func(instance)
        instance.__dict__[self.func.__name__] = result
        return result

class Circle:
    def __init__(self, r):
        self.r = r

    @Cached
    def area(self):
        return 3.14 * self.r ** 2
```

## 49.3 数据描述符

有 `__set__` 或 `__delete__`，**优先级高于实例字典**。

```python
class Validated:
    def __init__(self, validator):
        self.validator = validator

    def __set_name__(self, owner, name):
        self.name = name

    def __get__(self, instance, owner):
        if instance is None:
            return self
        return instance.__dict__[self.name]

    def __set__(self, instance, value):
        if not self.validator(value):
            raise ValueError(f"{self.name} invalid: {value}")
        instance.__dict__[self.name] = value

class User:
    age = Validated(lambda v: 0 <= v <= 150)
```

## 49.4 描述符优先级

```
实例属性 < 数据描述符 < 实例字典 < 非数据描述符
```

## 49.5 property 是描述符

```python
# property 内部实现了 __get__/__set__/__delete__
class MyClass:
    @property
    def x(self):
        return self._x
```

## 49.6 实际描述符

- **property**：内置
- **classmethod**、**staticmethod**：描述符
- **super()**：描述符

## 49.7 字段验证

```python
class Positive:
    def __set__(self, instance, value):
        if value <= 0:
            raise ValueError("must be positive")
        instance.__dict__[self.name] = value

    def __get__(self, instance, owner):
        if instance is None:
            return self
        return instance.__dict__[self.name]

class Config:
    timeout = Positive()
```

## 49.8 缓存描述符

```python
class Memoized:
    def __init__(self, func):
        self.func = func
        self.cache = {}

    def __call__(self, *args):
        if args not in self.cache:
            self.cache[args] = self.func(*args)
        return self.cache[args]
```

## 49.9 何时用描述符

- 跨类复用的验证
- 缓存
- 自动属性管理
- ORM 字段

## 49.10 注意事项

- 描述符在类上，不在实例上
- `__set_name__` 在类创建时调用
- 数据描述符覆盖实例字典

## 小结

- 描述符 = 带 `__get__/__set__` 的对象
- property/classmethod/staticmethod 都是描述符
- 数据描述符优先级高
- 跨类复用用描述符
