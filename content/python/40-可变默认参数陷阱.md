# 第 9 章 进阶特性

# 40. 可变默认参数陷阱

## 学习目标

- 理解默认值求值时机
- 学会正确用法
- 避免共享状态

## 40.1 陷阱本质

默认值在**函数定义时**求值一次，所有调用共享。

```python
# 差
def f(lst=[]):
    lst.append(1)
    return lst

f()  # [1]
f()  # [1, 1]
f()  # [1, 1, 1]  共享同一对象
```

## 40.2 正确用法

```python
# 好
def f(lst=None):
    if lst is None:
        lst = []
    lst.append(1)
    return lst

f()  # [1]
f()  # [1]（独立）
```

## 40.3 其他可变默认值

```python
# 字典
def f(d={}):
    d["key"] = "value"
    return d

# 集合
def f(s=set()):
    s.add(1)
    return s
```

同样共享，都要改成 `None`。

## 40.4 不可变默认值安全

```python
def f(x=0):
    return x + 1
# 安全：int 不可变
```

## 40.5 检测共享

```python
def f(lst=None):
    if lst is None:
        lst = []
    return lst

a = f()
b = f()
print(a is b)  # False（独立）
```

## 40.6 实际场景

```python
# 差
def build_query(params={}, extra="x"):
    params["extra"] = extra
    return params

# 好
def build_query(params=None, extra="x"):
    if params is None:
        params = {}
    params["extra"] = extra
    return params
```

## 40.7 为什么这样设计

- 性能：默认值只求值一次
- 可预测：函数定义时确定行为
- 陷阱：可变对象共享

## 40.8 静态检查

linter（ruff、pylint）会警告 `B006`：mutable default。

## 小结

- 默认值只求值一次
- 可变默认值用 None 占位
- 函数体内创建新对象
- linter 能帮你检测
