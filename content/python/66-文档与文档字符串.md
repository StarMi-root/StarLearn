## 66.1 docstring 基础

```python
def calculate_area(radius):
    """计算圆的面积。

    Args:
        radius: 圆的半径，必须为正数。

    Returns:
        圆的面积。

    Raises:
        ValueError: 当半径 <= 0 时。

    Examples:
        >>> calculate_area(1)
        3.14159
    """
    if radius <= 0:
        raise ValueError("radius must be positive")
    return 3.14159 * radius ** 2
```

## 66.2 Google 风格

```python
def func(param1, param2=None):
    """一句话总结。

    详细描述（可选）。

    Args:
        param1: 参数 1 说明。
        param2: 参数 2 说明。

    Returns:
        返回值说明。

    Raises:
        ExceptionType: 何时抛出。

    Examples:
        >>> func(1)
        result
    """
```

## 66.3 NumPy 风格

```python
def func(x):
    """一句话总结。

    详细描述。

    Parameters
    ----------
    x : int
        参数说明。

    Returns
    -------
    result : int
        返回说明。
    """
```

## 66.9 陷阱

- 文档与代码脱节
- 过于详细
- 没有示例
- 拼写错误

## 66.10 最佳实践

- 每个公共 API 都有 docstring
- 示例可运行
- 文档随代码更新
- 自动检查拼写
