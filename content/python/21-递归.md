# 21. 递归

## 21.1 基本概念

递归 = 函数调用自身，必须有**基线条件**和**递归步骤**。

```python
def factorial(n):
    if n <= 1:        # 基线
        return 1
    return n * factorial(n - 1)  # 递归
```

## 21.2 经典例子

### 斐波那契

```python
def fib(n):
    if n <= 1:
        return n
    return fib(n - 1) + fib(n - 2)
```

注意：朴素版本是指数级 O(2ⁿ)。

### 阶乘

```python
def fact(n):
    return 1 if n <= 1 else n * fact(n - 1)
```

### 二分查找

```python
def binary_search(arr, target, lo=0, hi=None):
    if hi is None:
        hi = len(arr) - 1
    if lo > hi:
        return -1
    mid = (lo + hi) // 2
    if arr[mid] == target:
        return mid
    elif arr[mid] < target:
        return binary_search(arr, target, mid + 1, hi)
    else:
        return binary_search(arr, target, lo, mid - 1)
```

## 21.3 递归深度限制

```python
import sys
sys.getrecursionlimit()  # 默认 1000
```

超过会 `RecursionError`。

```python
sys.setrecursionlimit(10000)  # 谨慎提高
```

## 21.4 记忆化（Memoization）

```python
from functools import lru_cache

@lru_cache(maxsize=None)
def fib(n):
    if n <= 1:
        return n
    return fib(n - 1) + fib(n - 2)

fib(100)  # 瞬间完成
```

手写版本：

```python
def fib_memo(n, memo={}):
    if n in memo:
        return memo[n]
    if n <= 1:
        return n
    memo[n] = fib_memo(n - 1, memo) + fib_memo(n - 2, memo)
    return memo[n]
```

## 21.5 递归 vs 循环

| 场景 | 推荐 |
|------|------|
| 树/图遍历 | 递归 |
| 分治算法 | 递归 |
| 简单迭代 | 循环 |
| 深度很大 | 循环 + 显式栈 |

## 21.6 尾递归

Python **不支持**尾递归优化（TCO），尾递归仍会爆栈。

```python
# 尾递归（Python 仍会栈溢出）
def sum_to(n, acc=0):
    if n == 0:
        return acc
    return sum_to(n - 1, acc + n)
```

需要改成循环。

## 小结

- 递归必须有基线
- 深度大考虑循环或记忆化
- `@lru_cache` 是简单高效的记忆化
- 尾递归在 Python 中不优化
