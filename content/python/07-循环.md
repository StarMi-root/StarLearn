# 第 2 章 控制流

# 7. 循环

## 学习目标

- 掌握 for / while
- 理解 range()
- 学会 break / continue
- 了解 for...else 子句

## 7.1 for 循环

```python
for item in [1, 2, 3]:
    print(item)

for i in range(5):
    print(i)  # 0, 1, 2, 3, 4
```

## 7.2 range()

```python
list(range(5))         # [0, 1, 2, 3, 4]
list(range(2, 8))      # [2, 3, 4, 5, 6, 7]
list(range(0, 10, 2))  # [0, 2, 4, 6, 8]
list(range(5, 0, -1))  # [5, 4, 3, 2, 1]
```

range 不会真正生成所有数，是惰性对象，内存高效。

## 7.3 while 循环

```python
count = 0
while count < 5:
    print(count)
    count += 1
```

危险：可能无限循环，确保有退出条件。

## 7.4 break 与 continue

```python
for i in range(10):
    if i == 3:
        continue  # 跳过当前，继续下一次
    if i == 7:
        break     # 退出整个循环
    print(i)
# 输出: 0 1 2 4 5 6
```

## 7.5 for...else

循环**正常结束**（没有 break）时执行 else：

```python
# 找质数
def is_prime(n):
    if n < 2:
        return False
    for i in range(2, n):
        if n % i == 0:
            return False
    else:
        return True  # 循环没 break，说明没有因子
```

## 7.6 常见模式

### 遍历到索引

```python
fruits = ["apple", "banana", "cherry"]
for i, fruit in enumerate(fruits):
    print(i, fruit)
# 0 apple
# 1 banana
# 2 cherry
```

### 同时遍历两个序列

```python
names = ["Alice", "Bob"]
scores = [85, 92]
for name, score in zip(names, scores):
    print(f"{name}: {score}")
```

## 7.7 嵌套循环

```python
for i in range(3):
    for j in range(3):
        print(f"({i},{j})", end=" ")
    print()
# (0,0) (0,1) (0,2)
# (1,0) (1,1) (1,2)
# (2,0) (2,1) (2,2)
```

## 小结

- 优先用 for 而非 while
- range() 惰性高效
- break/continue 不要滥用，能重构就重构
- enumerate 替代手动索引
