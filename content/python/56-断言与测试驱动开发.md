## 56.1 assert 基础

```python
def add(a, b):
    assert a is not None, "a is None"
    return a + b
```

注意：`-O` 优化模式会移除 assert，**不要用于生产校验**。

## 56.2 assert vs 异常

```python
# assert（开发期）
assert x > 0, "x must be positive"

# 异常（生产期）
if x <= 0:
    raise ValueError("x must be positive")
```

## 56.3 TDD 流程

1. **红**：写失败的测试
2. **绿**：写最少代码让测试通过
3. **重构**：改进代码，保持测试通过

## 56.4 实际 TDD

### 需求：计算折扣价

#### 红

```python
# test_pricing.py
def test_discount():
    from pricing import apply_discount
    assert apply_discount(100, 0.1) == 90  # 还未实现
```

```bash
pytest test_pricing.py  # 失败
```

#### 绿

```python
# pricing.py
def apply_discount(price, discount):
    return price * (1 - discount)
```

```bash
pytest test_pricing.py  # 通过
```

#### 重构

```python
def apply_discount(price, discount):
    if not 0 <= discount <= 1:
        raise ValueError("discount out of range")
    return price * (1 - discount)
```

## 56.6 可测试设计

- 纯函数优先
- 依赖注入
- 小函数

```python
# 难测试
class Service:
    def process(self):
        db = Database()  # 硬编码依赖
        ...

# 易测试
class Service:
    def __init__(self, db):
        self.db = db
```

## 56.8 边界测试

```python
@pytest.mark.parametrize("input, expected", [
    (0, "empty"),
    (1, "one"),
    (-1, "negative"),
    (float("inf"), "inf"),
])
def test_classify(input, expected):
    assert classify(input) == expected
```
