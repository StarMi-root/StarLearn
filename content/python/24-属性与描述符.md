# 24. 属性与描述符

## 学习目标

- 掌握 property
- 学会 classmethod、staticmethod
- 理解描述符协议

## 24.1 property

```python
class Circle:
    def __init__(self, radius):
        self.radius = radius

    @property
    def area(self):
        return 3.14159 * self.radius ** 2

    @property
    def diameter(self):
        return 2 * self.radius

c = Circle(5)
print(c.area)  # 注意：没有括号！
```

### 带 setter

```python
class Person:
    def __init__(self, name):
        self.name = name
        self._age = 0

    @property
    def age(self):
        return self._age

    @age.setter
    def age(self, value):
        if value < 0 or value > 150:
            raise ValueError("age out of range")
        self._age = value

p = Person("Alice")
p.age = 30
# p.age = 200  # ValueError
```

### 带 deleter

```python
@age.deleter
def age(self):
    del self._age
```

## 24.2 为什么用 property

- 看起来像属性，实际是方法
- 可以加验证逻辑
- 对外接口不变，内部实现可改

## 24.3 @classmethod

```python
class Date:
    def __init__(self, day, month, year):
        self.day = day
        self.month = month
        self.year = year

    @classmethod
    def from_string(cls, s):
        day, month, year = map(int, s.split("-"))
        return cls(day, month, year)

    def display(self):
        return f"{self.day}/{self.month}/{self.year}"
```

classmethod 接收类本身（`cls`），常用于工厂方法。

## 24.4 @staticmethod

```python
class Math:
    @staticmethod
    def add(a, b):
        return a + b
```

staticmethod 不接收 self 或 cls，纯工具方法。

## 24.5 描述符协议

描述符 = 定义了 `__get__`、`__set__`、`__delete__` 之一的对象。

```python
class Validated:
    def __init__(self, name, validator):
        self.name = name
        self.validator = validator

    def __set_name__(self, owner, name):
        self.name = name

    def __get__(self, instance, owner):
        if instance is None:
            return self
        return instance.__dict__[self.name]

    def __set__(self, instance, value):
        if not self.validator(value):
            raise ValueError(f"{self.name} invalid")
        instance.__dict__[self.name] = value

class User:
    age = Validated("age", lambda v: 0 <= v <= 150)
```

property 内部就是描述符。

## 24.6 选择

| 需求 | 工具 |
|------|------|
| 计算属性 | property |
| 工厂方法 | classmethod |
| 工具函数 | staticmethod |
| 跨类复用验证 | 描述符 |

## 小结

- property 让属性有"行为"
- classmethod 接收 cls
- staticmethod 不接收 self/cls
- 描述符是 property 的底层机制
