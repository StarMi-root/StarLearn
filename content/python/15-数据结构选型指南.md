# 15. 数据结构选型指南

## 学习目标

- 根据场景选对数据结构
- 理解各结构的复杂度
- 掌握典型使用模式

## 15.1 复杂度速查

| 操作 | list | tuple | dict | set |
|------|------|-------|------|-----|
| 按索引访问 | O(1) | O(1) | — | — |
| 按值查找 | O(n) | O(n) | O(1) | O(1) |
| 插入末尾 | O(1)* | — | O(1) | O(1)* |
| 插入开头 | O(n) | — | O(1) | O(1)* |
| 删除指定 | O(n) | — | O(1) | O(1) |

*摊还

## 15.2 选型原则

### 需要有序、可修改 → list

```python
items = []
items.append(1)
items.sort()
```

### 需要固定结构 → tuple

```python
point = (1, 2, 3)
color = (255, 128, 0)
```

### 需要键值映射 → dict

```python
config = {"host": "localhost", "port": 8080}
counts = {}
for word in words:
    counts[word] = counts.get(word, 0) + 1
```

### 需要去重、成员判断 → set

```python
seen = set()
for x in data:
    if x not in seen:
        seen.add(x)
```

### 需要保序 + 成员判断 → dict（Python 3.7+）

```python
seen = {}
for x in data:
    seen[x] = True
# dict 保序
```

## 15.3 典型场景

### 统计词频

```python
from collections import Counter
words = ["a", "b", "a", "c", "a"]
counter = Counter(words)
print(counter.most_common(2))  # [('a', 3), ('b', 1)]
```

### 队列

```python
from collections import deque
q = deque()
q.append(1)     # 入队（末尾）
q.popleft()     # 出队（开头，O(1)）
```

### 栈

```python
stack = []
stack.append(x)   # 入栈
stack.pop()       # 出栈
```

### 双向链表

```python
from collections import deque
dq = deque([1, 2, 3])
dq.appendleft(0)
dq.append(4)
```

## 15.4 何时用什么

| 需求 | 推荐 |
|------|------|
| 有序集合 | list / set |
| 映射 | dict |
| 快速成员判断 | set / dict |
| 去重保序 | `dict.fromkeys(iterable)` 或 set |
| 计数 | collections.Counter |
| 队列 | collections.deque |
| 固定结构 | tuple / dataclass |
| 图邻接表 | dict of list |

## 15.5 collections 模块

```python
from collections import defaultdict, OrderedDict, namedtuple, deque, Counter
```

- `defaultdict(int)`：未定义的键返回 0
- `OrderedDict`：显式保序（3.7+ dict 已保序）
- `namedtuple`：轻量不可变记录
- `deque`：双端队列
- `Counter`：计数

## 小结

- 默认用 dict/set 做成员判断
- 有序可变用 list
- 固定结构用 tuple
- 特殊需求用 collections 工具
