# 69. 常见陷阱与最佳实践清单

## 学习目标

- 避免常见陷阱
- 掌握最佳实践
- 代码审查要点

## 69.1 可变默认参数

```python
# 差
def f(lst=[]): ...

# 好
def f(lst=None):
    if lst is None:
        lst = []
```

## 69.2 浮点相等

```python
# 差
0.1 + 0.2 == 0.3  # False

# 好
abs((0.1 + 0.2) - 0.3) < 1e-9
```

## 69.3 字符串拼接

```python
# 差
result = ""
for word in words:
    result += word

# 好
result = "".join(words)
```

## 69.4 深拷贝

```python
# 嵌套列表
a = [[1, 2], [3, 4]]
b = a[:]  # 浅拷贝
b[0].append(5)  # 影响 a
```

## 69.5 循环变量

```python
# 差
funcs = [lambda: i for i in range(5)]
[f() for f in funcs]  # [4, 4, 4, 4, 4]

# 好
funcs = [lambda i=i: i for i in range(5)]
```

## 69.6 异常吞掉

```python
# 差
try:
    ...
except:
    pass

# 好
try:
    ...
except SpecificError as e:
    logging.warning("failed: %s", e)
```

## 69.7 可变数据默认

```python
# 差
class Config:
    items = []  # 类属性，共享

# 好
class Config:
    def __init__(self):
        self.items = []
```

## 69.8 字符串驻留

```python
# 不要依赖
a = "abc"
b = "abc"
a is b  # 可能 True，可能 False
```

## 69.9 比较陷阱

```python
# 差
if x == None: ...

# 好
if x is None: ...
```

## 69.10 迭代修改

```python
# 差
for item in lst:
    if condition:
        lst.remove(item)  # 跳过元素

# 好
lst = [x for x in lst if not condition(x)]
```

## 69.11 全局变量

```python
# 差
count = 0
def f():
    global count
    count += 1

# 好
class Counter:
    def __init__(self):
        self.count = 0
```
