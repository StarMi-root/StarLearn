## 19.1 LEGB 规则

Python 查找变量顺序：

1. **L**ocal — 函数内部
2. **E**nclosing — 外层函数
3. **G**lobal — 模块全局
4. **B**uilt-in — 内置（print, len...）

```python
x = "global"

def outer():
    x = "enclosing"
    def inner():
        # x = "local"
        print(x)  # "enclosing"（来自外层函数）

outer()
```

## 19.2 global 与 nonlocal

```python
count = 0

def increment():
    global count
    count += 1
```

```python
def outer():
    x = 10
    def inner():
        nonlocal x
        x += 1
    return inner

f = outer()
f()  # x 变成 11
```

## 19.3 闭包

闭包 = 函数 + 它引用的外层变量

```python
def make_multiplier(n):
    def multiply(x):
        return x * n
    return multiply

double = make_multiplier(2)
triple = make_multiplier(3)

print(double(5))   # 10
print(triple(5))   # 15
```

`multiply` 记住了 `n` 的值。

## 19.4 闭包陷阱

```python
# 差
funcs = []
for i in range(5):
    funcs.append(lambda: i)

[f() for f in funcs]  # [4, 4, 4, 4, 4]
```

修复：

```python
funcs = []
for i in range(5):
    funcs.append(lambda i=i: i)
# 默认值捕获当前 i
```

## 19.5 实际应用场景

### 装饰器（基于闭包）

```python
def log_calls(func):
    def wrapper(*args, **kwargs):
        print(f"calling {func.__name__}")
        return func(*args, **kwargs)
    return wrapper
```

### 配置工厂

```python
def make_adder(base):
    def add(x):
        return x + base
    return add

add10 = make_adder(10)
add10(5)  # 15
```

## 小结

- LEGB 决定变量查找顺序
- 闭包让函数"记住"外层状态
- 用 `nonlocal` 修改外层变量
- 闭包陷阱用默认值捕获
