# 第 5 章 面向对象编程

# 22. 类与对象

## 学习目标

- 学会定义类
- 理解 __init__ 与实例
- 掌握 self 的含义
- 区分类属性与实例属性

## 22.1 基本语法

```python
class Dog:
    def __init__(self, name, age):
        self.name = name
        self.age = age

    def bark(self):
        print(f"{self.name} says woof!")

rex = Dog("Rex", 5)
rex.bark()  # Rex says woof!
```

## 22.2 self 是什么

`self` 是当前实例的引用，约定第一个参数名。

```python
class Counter:
    def __init__(self):
        self.count = 0

    def increment(self):
        self.count += 1

c = Counter()
c.increment()
```

## 22.3 类属性 vs 实例属性

```python
class ClassRoom:
    school = "MIT"  # 类属性（所有实例共享）

    def __init__(self, room_no):
        self.room_no = room_no  # 实例属性

a = ClassRoom(101)
b = ClassRoom(202)
print(a.school, b.school)  # MIT MIT
a.school = "Harvard"
print(b.school)             # MIT（类属性未变）
```

## 22.4 实例方法 vs 类方法 vs 静态方法

```python
class MyClass:
    class_var = "x"

    @classmethod
    def from_string(cls, s):
        return cls(s)

    @staticmethod
    def helper(x):
        return x * 2

    def instance_method(self):
        return self.class_var
```

## 22.5 多重继承（初步）

```python
class A:
    def hello(self):
        return "A"

class B:
    def hello(self):
        return "B"

class C(A, B):
    pass

C().hello()  # "A"（MRO 决定）
```

## 22.6 属性命名

```python
class MyClass:
    def __init__(self):
        self._private = "convention"
        self.__name_mangled = "truly hidden"

    def get(self):
        return self._private
```

- `_x`：约定"内部"
- `__x`：名称修饰，防止子类意外访问

## 22.7 访问私有

```python
class MyClass:
    def __init__(self, value):
        self._value = value

    @property
    def value(self):
        return self._value

    @value.setter
    def value(self, new):
        if new < 0:
            raise ValueError
        self._value = new
```

## 小结

- `__init__` 是构造器
- `self` 指向当前实例
- 类属性共享，实例属性独立
- 用 property 控制访问
