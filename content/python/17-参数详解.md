# 第 4 章 函数

# 17. 参数详解

## 学习目标

- 掌握 *args、**kwargs
- 理解参数求值顺序
- 学会限制关键字参数
- 掌握参数校验

## 17.1 参数顺序

```python
def f(pos, /, kw1, kw2=None, *args, **kwargs):
    ...
```

- `pos`：仅位置
- `kw1, kw2`：位置或关键字
- `*args`：剩余位置参数（元组）
- `**kwargs`：剩余关键字参数（字典）

`/` 分隔位置专用参数。

## 17.2 *args

```python
def sum_all(*nums):
    total = 0
    for n in nums:
        total += n
    return total

sum_all(1, 2, 3)       # 6
sum_all(*[1, 2, 3])    # 解包
```

## 17.3 **kwargs

```python
def log(**fields):
    for k, v in fields.items():
        print(f"{k}: {v}")

log(level="INFO", msg="started")
```

## 17.4 位置专用与关键字专用

```python
def f(x, /, y=1, *, z=2):
    return x, y, z

f(1, y=3, z=5)  # (1, 3, 5)
```

## 17.5 解包调用

```python
args = (1, 2)
kwargs = {"b": 20}
def f(a, b):
    return a + b

f(*args, **kwargs)  # 21
```

## 17.6 参数校验

```python
def set_age(age):
    if not isinstance(age, int):
        raise TypeError("age must be int")
    if age < 0 or age > 150:
        raise ValueError("age out of range")
```

## 17.7 默认值陷阱回顾

```python
# 差
def f(lst=[]):
    lst.append(1)
    return lst

# 好
def f(lst=None):
    if lst is None:
        lst = []
    lst.append(1)
    return lst
```

## 17.8 参数注解（初步）

```python
def f(x: int, y: float = 0.0, /, z: str = "") -> int:
    return int(x + y + len(z))
```

注解只是提示，Python 不强制。

## 小结

- 参数顺序：位置 → 位置或关键字 → *args → 关键字专用 → **kwargs
- `*args` 收集剩余位置参数
- `**kwargs` 收集剩余关键字参数
- 默认值用不可变对象或 None
