# 第 8 章 文件与 I/O

# 35. 文件读写

## 学习目标

- 掌握 open() 模式
- 学会读写文本与二进制
- 理解 with 语句

## 35.1 open() 模式

```python
f = open("data.txt", "r")     # 读（默认）
f = open("data.txt", "w")     # 写（清空）
f = open("data.txt", "a")     # 追加
f = open("data.bin", "rb")    # 二进制读
f = open("data.bin", "wb")    # 二进制写
f = open("data.txt", "r+",)   # 读写
```

## 35.2 读取

```python
# 全部
with open("data.txt") as f:
    text = f.read()

# 逐行
with open("data.txt") as f:
    for line in f:
        print(line, end="")

# 列表
with open("data.txt") as f:
    lines = f.readlines()
```

## 35.3 写入

```python
with open("out.txt", "w") as f:
    f.write("hello\n")
    f.write("world\n")

# 追加
with open("out.txt", "a") as f:
    f.write("more\n")
```

## 35.4 二进制文件

```python
with open("img.png", "rb") as f:
    data = f.read()

with open("out.png", "wb") as f:
    f.write(data)
```

## 35.5 上下文管理

```python
# 推荐
with open("data.txt") as f:
    data = f.read()
# 自动关闭

# 不推荐
f = open("data.txt")
data = f.read()
f.close()  # 异常时可能不执行
```

## 35.6 编码

```python
with open("data.txt", encoding="utf-8") as f:
    text = f.read()

# 默认编码由系统决定，显式指定更安全
```

## 35.7 大文件处理

```python
# 逐行读取（内存友好）
with open("huge.csv") as f:
    for line in f:
        process(line)
```

## 35.8 临时文件

```python
import tempfile
with tempfile.NamedTemporaryFile(delete=False, suffix=".txt") as f:
    f.write(b"data")
    tmp_name = f.name
# 使用 tmp_name
os.unlink(tmp_name)
```

## 35.9 常见陷阱

```python
# 忘记 with
f = open("data.txt")
data = f.read()
# 忘记 f.close()

# 模式错误
with open("data.txt", "r") as f:
    f.write("x")  # io.UnsupportedOperation
```

## 小结

- 永远用 `with open(...)`
- 显式指定编码
- 大文件逐行处理
- 二进制模式用 "b"
