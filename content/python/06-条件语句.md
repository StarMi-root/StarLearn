# 第 2 章 控制流

# 6. 条件语句

## 学习目标

- 掌握 if / elif / else
- 理解真值规则
- 学会用三元表达式简化

## 6.1 基本语法

```python
x = 10

if x > 0:
    print("正数")
elif x == 0:
    print("零")
else:
    print("负数")
```

## 6.2 嵌套与组合

```python
age = 20
income = 50000

if age >= 18:
    if income > 30000:
        print("可贷款")
    else:
        print("收入不足")
else:
    print("未成年")
```

可以合并为单行：

```python
if age >= 18 and income > 30000:
    print("可贷款")
```

## 6.3 真值规则

```python
if "hello":       # 非空字符串 → True
if 0:             # 0 → False
if []:            # 空列表 → False
if {"a": 1}:     # 非空字典 → True
if None:          # None → False
```

## 6.4 三元表达式（条件表达式）

```python
x = 10
result = "偶数" if x % 2 == 0 else "奇数"
```

等价于：

```python
if x % 2 == 0:
    result = "偶数"
else:
    result = "奇数"
```

可嵌套，但不要超过两层：

```python
# 差
a = x if x > 0 else (-x if x < 0 else 0)

# 好（拆成函数）
def abs_value(x):
    if x > 0: return x
    if x < 0: return -x
    return 0
```

## 6.5 match-case（Python 3.10+）

```python
def http_status(code):
    match code:
        case 200:
            return "OK"
        case 404:
            return "Not Found"
        case _:
            return "Unknown"
```

## 小结

- 用 `and`/`or` 合并多个条件，避免过深嵌套
- 三元表达式只适合简单选择
- Python 3.10+ 可用 match-case 做结构化匹配
