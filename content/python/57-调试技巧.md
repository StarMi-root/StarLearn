## 57.3 pdb

```python
import pdb
pdb.set_trace()
```

常用命令：

```
(n) next    下一行
(s) step    进入函数
(c) continue 继续到断点
(p) print   查看变量
(l) list    查看代码
(w) where   调用栈
(q) quit    退出
(h) help    帮助
```

## 57.4 条件断点

```python
import sys
if some_condition:
    pdb.set_trace()
```

## 57.5 postmortem 调试

```python
import pdb, sys

try:
    risky()
except Exception:
    pdb.post_mortem(sys.exc_info()[2])
```

## 57.7 日志调试

```python
import logging
logger = logging.getLogger(__name__)

def process(x):
    logger.debug("processing %s", x)
    result = transform(x)
    logger.debug("result: %s", result)
    return result
```

## 57.9 调试常见错误

| 现象 | 可能原因 |
|------|----------|
| 偶发失败 | 竞态条件、状态共享 |
| 内存泄漏 | 循环引用、未释放资源 |
| 性能慢 | 算法、I/O、循环 |
| 死循环 | 条件错误、递归无基线 |
