# 第 3 章 数据结构

# 11. 元组

## 学习目标

- 理解元组的不可变性
- 学会解包
- 了解元组作为字典键的用法

## 11.1 创建

```python
t = (1, 2, 3)
t = 1, 2, 3           # 不加括号也可以
t = (1,)              # 单元素元组必须加逗号
t = ()                # 空元组
```

注意：`(1)` 是整数 1，不是元组。

## 11.2 不可变性

```python
t = (1, 2, 3)
t[0] = 10  # TypeError
```

元组是**不可变**的。但要注意：

```python
t = ([1, 2], [3, 4])
t[0].append(3)  # 可以！元组本身不变，但内部列表可变
print(t)  # ([1, 2, 3], [3, 4])
```

## 11.3 解包

```python
a, b, c = (1, 2, 3)
x, y = 5, 10

# 交换
a, b = b, a

# 忽略
_, second, _ = (1, 2, 3)

# 星号解包
first, *rest = [1, 2, 3, 4]
# first=1, rest=[2,3,4]

a, *middle, b = [1, 2, 3, 4, 5]
# a=1, middle=[2,3,4], b=5
```

## 11.4 作为字典键

元组可哈希，可作键：

```python
coords = {(0, 0): "origin", (1, 2): "point"}
print(coords[(1, 2)])  # "point"
```

列表不行（不可哈希）：

```python
d = {[[1, 2]]: "x"}  # TypeError: unhashable type: 'list'
```

## 11.5 元组 vs 列表

| 特性 | 列表 | 元组 |
|------|------|------|
| 可变 | 是 | 否 |
| 性能 | 略慢 | 略快 |
| 可哈希 | 否 | 是（元素可哈希时） |
| 用途 | 集合 | 固定结构 / 记录 |

## 11.6 何时用元组

- 固定结构的数据（坐标、RGB 颜色、数据库行）
- 函数返回多个值
- 字典的键
- 需要安全不可变时

## 11.7 元组方法

```python
t = (1, 2, 3, 2, 1)
t.count(2)  # 2
t.index(3)  # 2
```

## 小结

- 元组不可变，可哈希
- 解包语法 `a, b = t` 很常用
- 固定结构数据优先用元组
- 内部可变对象会让"不可变"名不副实
