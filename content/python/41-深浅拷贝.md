# 第 9 章 进阶特性

# 41. 深浅拷贝

## 学习目标

- 理解浅拷贝与深拷贝
- 学会 copy 与 deepcopy
- 避免共享陷阱

## 41.1 引用 vs 拷贝

```python
a = [1, 2, 3]
b = a            # 引用同一对象
b.append(4)
print(a)         # [1, 2, 3, 4]

b = a[:]         # 浅拷贝（切片）
b.append(4)
print(a)         # [1, 2, 3]
```

## 41.2 浅拷贝

```python
import copy

original = [[1, 2], [3, 4]]
shallow = copy.copy(original)
shallow[0].append(5)

print(original)  # [[1, 2, 5], [3, 4]]  内层被改
print(shallow)   # [[1, 2, 5], [3, 4]]
```

浅拷贝只复制外层，内层仍共享。

## 41.3 深拷贝

```python
deep = copy.deepcopy(original)
deep[0].append(6)

print(original)  # [[1, 2, 5], [3, 4]]
print(deep)      # [[1, 2, 5, 6], [3, 4]]
```

## 41.4 何时用深拷贝

- 嵌套可变结构（list of dict）
- 需要完全独立副本
- 传递给外部 API 前

## 41.5 性能考虑

- 深拷贝递归复制，开销大
- 浅拷贝通常更快
- 不可变对象（str、tuple、int）拷贝无意义

## 41.6 自定义拷贝

```python
class MyData:
    def __init__(self, data):
        self.data = data

    def copy(self):
        return MyData(copy.deepcopy(self.data))
```

## 41.7 常见陷阱

```python
# 嵌套列表
a = [[1, 2], [3, 4]]
b = a[:]  # 浅拷贝
b[0].append(5)
print(a[0])  # [1, 2, 5]（被改）

# 字典
d = {"key": {"nested": 1}}
e = d.copy()  # 浅拷贝
e["key"]["nested"] = 99
print(d["key"]["nested"])  # 99
```

## 41.8 替代方案

- 不可变数据结构（tuple、frozen dataclass）
- 重新创建而非拷贝
- 函数式风格避免修改

## 41.9 检测

```python
import sys
# 简单判断
def is_shared(a, b):
    return any(id(x) == id(y) for x, y in zip(flatten(a), flatten(b)))
```

## 小结

- `copy.copy` 浅拷贝
- `copy.deepcopy` 深拷贝
- 嵌套结构用深拷贝
- 优先用不可变结构避免拷贝问题
