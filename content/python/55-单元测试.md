# 55. 单元测试

## 学习目标

- 掌握 unittest
- 学会 pytest
- 理解 fixture

## 55.1 unittest 基础

```python
import unittest

class TestMath(unittest.TestCase):
    def test_add(self):
        self.assertEqual(1 + 1, 2)

    def test_sub(self):
        self.assertTrue(5 > 3)

    def test_divide(self):
        with self.assertRaises(ZeroDivisionError):
            1 / 0

if __name__ == "__main__":
    unittest.main()
```

## 55.2 断言方法

```python
self.assertEqual(a, b)
self.assertNotEqual(a, b)
self.assertIs(a, b)
self.assertIsNot(a, b)
self.assertTrue(x)
self.assertFalse(x)
self.assertIn(a, b)
self.assertNotIn(a, b)
self.assertRaises(ExceptionType)
self.assertGreater(a, b)
self.assertLess(a, b)
```

## 55.3 setUp 与 tearDown

```python
class TestDB(unittest.TestCase):
    def setUp(self):
        self.conn = create_conn()
    def tearDown(self):
        self.conn.close()
```

## 55.4 pytest（推荐）

```python
# test_math.py
def test_add():
    assert 1 + 1 == 2

def test_sub():
    assert 5 - 3 == 2
```

运行：

```bash
pytest test_math.py -v
```

## 55.5 fixture

```python
import pytest

@pytest.fixture
def sample_data():
    return [1, 2, 3]

def test_sum(sample_data):
    assert sum(sample_data) == 6
```

## 55.6 参数化

```python
@pytest.mark.parametrize("x, expected", [
    (1, 1), (2, 4), (3, 9)
])
def test_square(x, expected):
    assert x * x == expected
```

## 55.7 mock

```python
from unittest.mock import patch, Mock

@patch("mymodule.network_call")
def test_api(mock_call):
    mock_call.return_value = {"status": "ok"}
    result = mymodule.fetch()
    assert result["status"] == "ok"
    mock_call.assert_called_once()
```

## 55.10 陷阱

- 测试之间隔离
- 不依赖执行顺序
- 不访问外部资源
- mock 副作用

## 小结

- pytest 更简洁
- fixture 复用数据
- mock 外部依赖
- 覆盖率监控
