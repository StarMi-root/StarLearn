# 第 1 章 入门基础

# 3. 运算符与表达式

## 学习目标

- 掌握算术、比较、逻辑、赋值、位运算
- 理解运算优先级
- 避免常见陷阱

## 3.1 算术运算符

```python
+  加法
-  减法
*  乘法
/  真除法（结果始终是 float）
// 整除（向下取整）
%  取模
** 幂
```

```python
7 / 2    # 3.5
7 // 2   # 3
-7 // 2  # -4（向下取整，向负无穷方向）
2 ** 10  # 1024
10 % 3   # 1
-7 % 2   # 1（Python 的取模结果符号跟除数走）
```

## 3.2 比较运算符

返回布尔值：

```python
==  等于
!=  不等于
<   小于
>   大于
<=  小于等于
>=  大于等于
is  同一对象
is not  不是同一对象
```

```python
1 == 1.0       # True（值相等）
1 is 1.0       # False（不同对象）
"abc" == "abc" # True
"abc" is "abc" # 小字符串可能 True（驻留），不要依赖
```

## 3.3 逻辑运算符

```python
and  逻辑与
or   逻辑或
not  逻辑非
```

短路求值：

```python
# and：返回第一个为假的那个，否则返回最后一个
0 and 1    # 0
2 and 3    # 3
"" and "hi"  # ""

# or：返回第一个为真的那个，否则返回最后一个
0 or "hi"   # "hi"
"" or []     # []
```

## 3.4 赋值运算符

```python
=    赋值
+=   加后赋值
-=   减后赋值
*=   乘后赋值
/=   除后赋值
//=  整除后赋值
%=   取模后赋值
**=  幂后赋值
```

## 3.5 位运算符

```python
&  按位与
|  按位或
^  按位异或
~  按位取反
<< 左移
>> 右移
```

```python
5 & 3    # 1  (0101 & 0011 = 0001)
5 | 3    # 7  (0101 | 0011 = 0111)
5 ^ 3    # 6  (0101 ^ 0011 = 0110)
1 << 3   # 8
8 >> 2   # 2
```

## 3.6 运算优先级（从高到低）

```
()       括号
**       幂
-        一元
* / // % 乘除
+ -      加减
&        与
^        异或
|        或
比较     == != < > <= >= is in
not
and
or
```

## 3.7 常见陷阱

```python
# 浮点比较
0.1 + 0.2 == 0.3   # False
abs((0.1 + 0.2) - 0.3) < 1e-9  # True

# 链式比较
1 < 2 < 3          # True（等价于 1<2 且 2<3）
```

## 小结

- `//` 是向下取整，不是截断
- Python 取模结果符号跟除数
- `and`/`or` 短路求值
- 浮点相等比较用 `abs(a-b) < epsilon`
