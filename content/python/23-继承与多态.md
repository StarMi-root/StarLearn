## 23.1 基本继承

```python
class Animal:
    def __init__(self, name):
        self.name = name

    def speak(self):
        return "..."

class Dog(Animal):
    def speak(self):
        return "woof"

class Cat(Animal):
    def speak(self):
        return "meow"
```

## 23.2 super()

```python
class Animal:
    def __init__(self, name):
        self.name = name

class Dog(Animal):
    def __init__(self, name, breed):
        super().__init__(name)
        self.breed = breed
```

## 23.3 MRO（方法解析顺序）

```python
class A:
    def who(self): return "A"

class B(A):
    def who(self): return "B"

class C(A):
    def who(self): return "C"

class D(B, C):
    pass

D.mro()
# [D, B, C, A, object]
```

用 C3 线性化算法决定。

## 23.4 多态

```python
def make_sound(animal):
    print(animal.speak())

make_sound(Dog("Rex"))   # woof
make_sound(Cat("Mimi"))  # meow
```

不关心具体类型，只关心**行为**。

## 23.5 isinstance 与 issubclass

```python
d = Dog("Rex")
isinstance(d, Dog)     # True
isinstance(d, Animal)  # True（父类）

issubclass(Dog, Animal)  # True
```

## 23.6 接口思想

```python
class Shape:
    def area(self):
        raise NotImplementedError

class Circle(Shape):
    def __init__(self, r):
        self.r = r
    def area(self):
        return 3.14159 * self.r ** 2

class Square(Shape):
    def __init__(self, s):
        self.s = s
    def area(self):
        return self.s ** 2

for shape in [Circle(2), Square(3)]:
    print(shape.area())
```

## 23.8 继承 vs 组合

```python
# 继承
class Bird(Animal):
    ...

# 组合
class Engine:
    def start(self): ...

class Car:
    def __init__(self):
        self.engine = Engine()
```

原则：**优先组合**。继承表达"是"关系，组合表达"有"关系。

## 小结

- super() 调用父类方法
- MRO 决定方法查找顺序
- 多态 = 同一接口不同实现
- 能组合就组合
