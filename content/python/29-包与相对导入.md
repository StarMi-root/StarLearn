# 第 6 章 模块与包

# 29. 包与相对导入

## 学习目标

- 掌握包结构
- 学会相对导入
- 理解 __init__.py 的作用

## 29.1 包结构

```
myproject/
  mypackage/
    __init__.py
    module_a.py
    module_b.py
    subpackage/
      __init__.py
      module_c.py
```

## 29.2 __init__.py

- 标记目录为包
- 可写初始化代码
- 可控制包的公开接口

```python
# mypackage/__init__.py
from .module_a import ClassA
from .module_b import ClassB

__all__ = ["ClassA", "ClassB"]
```

外部可以：

```python
from mypackage import ClassA
```

## 29.3 相对导入

```python
# mypackage/subpackage/module_c.py
from ..module_a import ClassA   # 父包的模块
from . import module_d           # 同包模块
```

- 一个点 `.` = 当前包
- 两个点 `..` = 父包

**只能在包内使用**，不能用于顶层脚本。

## 29.4 绝对导入 vs 相对导入

```python
# 绝对导入
from mypackage.module_a import ClassA

# 相对导入（在 mypackage/subpackage/module_c.py 中）
from ..module_a import ClassA
```

推荐：**对外用绝对导入，包内部用相对导入**。

## 29.5 包的 __all__

```python
__all__ = ["public_api_1", "public_api_2"]
```

控制 `from module import *` 的导出。

## 29.6 命名空间包

没有 `__init__.py` 的目录可被多个位置合并：

```
site-packages/mypkg/part1/
site-packages/mypkg/part2/
```

两者合并为同一个 `mypkg`。

## 29.7 常见错误

```python
# 顶层脚本不能用相对导入
from . import x  # ImportError: attempted relative import with no known parent package
```

必须作为包的一部分运行：

```bash
python -m mypackage.module
```

## 小结

- `__init__.py` 让目录成为包
- 相对导入用点
- `__all__` 控制导出
- 顶层脚本用绝对导入
