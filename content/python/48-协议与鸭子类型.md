# 第 9 章 进阶特性

# 48. 协议与鸭子类型

## 学习目标

- 理解鸭子类型
- 掌握 Protocol
- 学会结构化子类型

## 48.1 鸭子类型

"如果它走起来像鸭子、叫起来像鸭子，那它就是鸭子。"

```python
def process(obj):
    if obj:
        for item in obj:
            print(item)

process([1, 2, 3])       # list
process((1, 2, 3))       # tuple
process({1: "a"});       # dict（遍历键）
```

不关心具体类型，只关心行为。

## 48.2 鸭子类型的局限

- 错误晚到运行时
- 没有 IDE 提示
- 没有类型检查

## 48.3 Protocol

```python
from typing import Protocol, runtime_checkable

@runtime_checkable
class Readable(Protocol):
    def read(self, size: int = -1) -> bytes: ...

@runtime_checkable
class Writable(Protocol):
    def write(self, data: bytes) -> int: ...

def dump(obj: Writable, data: bytes) -> int:
    return obj.write(data)
```

## 48.4 结构化子类型

任何实现 `write(bytes) -> int` 的对象都符合 `Writable`：

```python
class MyWriter:
    def write(self, data: bytes) -> int:
        print(data)
        return len(data)

isinstance(MyWriter(), Writable)  # True
```

不需要继承。

## 48.5 runtime_checkable

```python
@runtime_checkable
class Shape(Protocol):
    def area(self) -> float: ...

def total(shapes: list[Shape]) -> float:
    return sum(s.area() for s in shapes)
```

注意：`runtime_checkable` 只检查方法**存在**，不检查签名。

## 48.6 Protocol vs ABC

| 特性 | Protocol | ABC |
|------|----------|-----|
| 继承 | 不需要 | 需要 |
| 强制 | 检查存在 | 抽象方法 |
| 灵活性 | 高 | 低 |
| 适用 | 鸭子类型 | 明确契约 |

## 48.7 实际场景

```python
# 任何可迭代对象
from typing import Iterable

def process(items: Iterable[int]) -> int:
    return sum(items)

process([1, 2, 3])
process((1, 2, 3))
process(iter([1, 2, 3]))
```

## 48.8 与泛型组合

```python
from typing import Protocol, Generic, TypeVar

T = TypeVar("T")

class Container(Protocol[T]):
    def add(self, item: T) -> None: ...
    def get(self, index: int) -> T: ...
```

## 48.9 最佳实践

- 接口稳定用 Protocol
- 需要强制契约用 ABC
- 鸭子类型 + Protocol 注解
- 配合 mypy 验证

## 48.10 限制

- 运行时检查有限
- 方法存在 ≠ 行为正确
- 复杂协议用 ABC

## 小结

- Protocol 是结构化子类型
- 不需要继承
- 鸭子类型更灵活
- 运行时检查有限
