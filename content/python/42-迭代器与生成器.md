# 42. 迭代器与生成器

## 学习目标

- 理解迭代协议
- 学会 yield
- 掌握生成器优势
- 避免无限生成器

## 42.1 迭代协议

可迭代对象实现 `__iter__`：

```python
class MyList:
    def __init__(self, items):
        self.items = items

    def __iter__(self):
        return iter(self.items)
```

迭代器实现 `__iter__` 和 `__next__`：

```python
class MyIterator:
    def __init__(self, items):
        self.items = items
        self.index = 0

    def __iter__(self):
        return self

    def __next__(self):
        if self.index >= len(self.items):
            raise StopIteration
        value = self.items[self.index]
        self.index += 1
        return value
```

## 42.2 生成器

```python
def my_range(n):
    i = 0
    while i < n:
        yield i
        i += 1

for x in my_range(5):
    print(x)  # 0 1 2 3 4
```

`yield` 让函数变成生成器。

## 42.3 生成器优势

- **惰性**：按需生成，内存高效
- **状态保持**：暂停在 yield 处
- **可组合**：生成器管道

```python
# 管道
def gen1():
    yield from range(10)

def gen2():
    for x in gen1():
        yield x * 2

list(gen2())  # [0, 2, 4, ..., 18]
```

## 42.4 生成器表达式

```python
# 等价
g = (x * x for x in range(10))
g2 = (x for x in g if x % 2 == 0)
```

## 42.5 状态

```python
def counter():
    n = 0
    while True:
        yield n
        n += 1

c = counter()
next(c)  # 0
next(c)  # 1
next(c)  # 2
```

## 42.6 无限生成器陷阱

```python
def infinite():
    n = 0
    while True:
        yield n
        n += 1

list(infinite())  # 内存溢出！
```

用 `itertools.islice` 限制：

```python
from itertools import islice
list(islice(infinite(), 10))  # [0..9]
```

## 42.7 生成器与迭代器区别

- 迭代器：`__next__` 手动
- 生成器：`yield` 语法糖

## 42.8 send 与 throw

```python
def my_gen():
    while True:
        received = yield
        print(received)

g = my_gen()
next(g)  # 启动
g.send(1)  # 1
```

## 42.9 何时用

- 大数据流处理
- 无限序列
- 惰性计算
- 状态机

## 42.10 注意事项

- 生成器只能遍历一次
- 不能随机访问
- `yield from` 委托给子生成器

## 小结

- yield 让函数变成生成器
- 惰性高效
- 无限生成器要限制
- 生成器管道很强大
