# 第 1 章 入门基础

# 2. 变量与数据类型

## 学习目标

- 理解变量如何赋值
- 掌握基本数据类型：int、float、str、bool、None
- 学会类型转换与 type()

## 2.1 变量赋值

Python 中变量不需要声明类型：

```python
x = 10          # 整数
name = "Alice"  # 字符串
pi = 3.14159    # 浮点数
is_admin = True # 布尔
nothing = None  # 空值
```

变量本质上是"标签"，指向内存中的对象。

```python
a = 5
b = a   # b 和 a 指向同一个整数对象
a = 10  # a 指向新对象，b 仍是 5
print(b)  # 5
```

## 2.2 整数 int

- 任意精度，没有上限
- 支持 `//` 整除、`**` 幂运算、`%` 取模

```python
print(2 ** 10)   # 1024
print(7 // 2)    # 3
print(10 % 3)    # 1
```

## 2.3 浮点数 float

- IEEE 754 双精度，有精度误差

```python
print(0.1 + 0.2)  # 0.30000000000000004
```

需要精确计算时用 `decimal` 模块：

```python
from decimal import Decimal
print(Decimal("0.1") + Decimal("0.2"))  # 0.3
```

## 2.4 字符串 str

```python
s = "hello"
s2 = 'world'
s3 = """多行
字符串"""
```

## 2.5 布尔 bool

`bool` 是 `int` 的子类：

```python
True + True   # 2
bool(0)        # False
bool("hi")     # True
bool([])        # False
bool(0.0)       # False
```

"真值"规则：0、0.0、""、[]、{}、None 为 False，其余为 True。

## 2.6 None

表示"没有值"，单例：

```python
x = None
x is None  # True
```

## 2.7 类型转换

```python
int("42")      # 42
float("3.14")  # 3.14
str(100)       # "100"
bool(5)        # True

int(3.99)      # 3（截断，不是四舍五入）
```

## 2.8 查看类型

```python
type(42)        # <class 'int'>
type("hi")      # <class 'str'>
isinstance(42, int)  # True
```

`isinstance` 支持多类型：

```python
isinstance(42, (int, float))  # True
```

## 小结

- 变量是引用，不是盒子
- 五种基本类型：int、float、str、bool、None
- 用 `int()`、`float()`、`str()` 互相转换
- 用 `type()` 和 `isinstance()` 检查类型
