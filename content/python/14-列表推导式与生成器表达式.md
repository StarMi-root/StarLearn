# 14. 列表推导式与生成器表达式

## 学习目标

- 掌握列表推导式
- 学会条件推导
- 理解生成器表达式的惰性
- 了解其他推导式（字典、集合）

## 14.1 列表推导式

```python
squares = [x**2 for x in range(5)]
# [0, 1, 4, 9, 16]

evens = [x for x in range(20) if x % 2 == 0]
# [0, 2, 4, ..., 18]
```

等价于：

```python
squares = []
for x in range(5):
    squares.append(x**2)
```

## 14.2 嵌套推导

```python
matrix = [[1, 2, 3], [4, 5, 6], [7, 8, 9]]
flat = [x for row in matrix for x in row]
# [1, 2, 3, 4, 5, 6, 7, 8, 9]
```

注意顺序：`for row` 在外层，`for x` 在内层。

## 14.3 字典推导式

```python
d = {i: i**2 for i in range(5)}
# {0: 0, 1: 1, 2: 4, 3: 9, 4: 16}

inverted = {v: k for k, v in d.items()}
```

## 14.4 集合推导式

```python
unique = {abs(x) for x in [-1, 1, -2, 2, 3]}
# {1, 2, 3}
```

## 14.5 生成器表达式

```python
g = (x**2 for x in range(5))  # 注意是圆括号
sum(g)  # 30（只能遍历一次）
```

生成器是**惰性**的，不生成全部结果，内存高效：

```python
# 差：生成 100 万个数
total = sum([x for x in range(1000000)])

# 好：生成器
total = sum(x for x in range(1000000))
```

## 14.6 何时用哪种

| 场景 | 选择 |
|------|------|
| 需要多次遍历 | 列表推导 |
| 只用一次、数据量大 | 生成器表达式 |
| 嵌套超过两层 | 改用普通循环 |
| 可读性差 | 改用普通循环 |

## 14.7 常见陷阱

```python
# 副作用
results = []
[x for x in range(5) if results.append(x)]
# results = [0,1,2,3,4]，但推导式本身返回 [None]*5
```

不要在推导式中做副作用操作。

## 14.8 性能对比

```python
import timeit

list_a = [x*x for x in range(1000)]      # 最快
list_b = list(map(lambda x: x*x, range(1000)))  # 略慢
list_c = [x*x for x in range(1000) if x % 2 == 0]  # 有过滤
```

## 小结

- 推导式简洁、可读
- 生成器表达式惰性，适合大数据
- 嵌套超过两层就拆开写
- 不要在推导式里做副作用
