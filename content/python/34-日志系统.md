# 第 7 章 异常与错误处理

# 34. 日志系统

## 学习目标

- 掌握 logging 模块
- 学会配置日志
- 了解日志级别

## 34.1 基本用法

```python
import logging

logging.basicConfig(
    level=logging.INFO,
    format="%(asctime)s %(levelname)s %(message)s"
)

logging.info("app started")
logging.warning("disk almost full")
logging.error("failed to connect")
logging.debug("variable x = 42")  # 默认不显示
```

## 34.2 日志级别

| 级别 | 数值 | 用途 |
|------|------|------|
| DEBUG | 10 | 开发调试 |
| INFO | 20 | 常规信息 |
| WARNING | 30 | 警告 |
| ERROR | 40 | 错误 |
| CRITICAL | 50 | 严重错误 |

## 34.3 获取 logger

```python
import logging
logger = logging.getLogger(__name__)
```

每个模块有自己的 logger，层级管理。

## 34.4 配置（字典配置）

```python
import logging.config

LOGGING_CONFIG = {
    "version": 1,
    "disable_existing_loggers": False,
    "formatters": {
        "standard": {
            "format": "%(asctime)s [%(levelname)s] %(name)s: %(message)s"
        }
    },
    "handlers": {
        "console": {
            "class": "logging.StreamHandler",
            "formatter": "standard",
            "stream": "ext://sys.stdout"
        },
        "file": {
            "class": "logging.FileHandler",
            "filename": "app.log",
            "formatter": "standard"
        }
    },
    "loggers": {
        "myapp": {
            "level": "DEBUG",
            "handlers": ["console", "file"],
            "propagate": False
        }
    },
    "root": {
        "level": "WARNING",
        "handlers": ["console"]
    }
}

logging.config.dictConfig(LOGGING_CONFIG)
```

## 34.5 多 handler

同一 logger 可挂多个 handler：

- 控制台：INFO 级别
- 文件：DEBUG 级别

```python
logger.info("to both")
logger.debug("only to file")
```

## 34.6 日志 vs print

| 特性 | print | logging |
|------|-------|---------|
| 级别 | 无 | 有 |
| 时间戳 | 手动 | 自动 |
| 多输出 | 困难 | 多 handler |
| 生产环境 | 难关闭 | 配置级别 |

## 34.7 结构化日志

```python
import json, logging

class JsonFormatter(logging.Formatter):
    def format(self, record):
        log_entry = {
            "time": self.formatTime(record),
            "level": record.levelname,
            "message": record.getMessage(),
            "module": record.module,
            "line": record.lineno
        }
        return json.dumps(log_entry)
```

## 34.8 捕获异常

```python
try:
    ...
except Exception:
    logger.exception("failed")  # 自动附带 traceback
```

## 小结

- 用 `logging.getLogger(__name__)`
- 配置级别与 handler
- 生产环境日志写文件
- `logger.exception()` 附带堆栈
