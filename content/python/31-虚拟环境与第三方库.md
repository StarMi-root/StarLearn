# 第 6 章 模块与包

# 31. 虚拟环境与第三方库

## 学习目标

- 理解虚拟环境
- 学会 pip 常用操作
- 掌握 requirements 管理

## 31.1 为什么需要虚拟环境

- 隔离项目依赖
- 避免版本冲突
- 可复现的环境

## 31.2 venv（推荐）

```bash
python -m venv venv
source venv/bin/activate   # macOS/Linux
venv\Scripts\activate      # Windows

# 验证
which python   # 应指向 venv 内
pip list

# 退出
deactivate
```

## 31.3 pip 常用命令

```bash
pip install requests          # 安装
pip install requests==2.31.0  # 指定版本
pip install -U requests       # 升级
pip uninstall requests        # 卸载
pip list                      # 已安装列表
pip show requests             # 详细信息
pip freeze > requirements.txt # 导出
pip install -r requirements.txt  # 从文件安装
```

## 31.4 常用包管理工具

| 工具 | 特点 |
|------|------|
| pip | 官方，最通用 |
| conda | 跨语言，适合数据科学 |
| poetry | 现代，依赖解析好 |
| uv | Rust 实现，极快 |
| pipenv | 集成 venv + pip |

## 31.5 requirements.txt

```
requests==2.31.0
flask>=2.0,<3.0
numpy
```

## 31.6 安装第三方库示例

```bash
pip install flask
pip install requests
pip install numpy pandas
```

## 31.7 包搜索

```bash
pip search    # PyPI 已禁用此命令，改用网页搜索
```

访问 https://pypi.org 搜索。

## 31.8 调试依赖

```bash
pip check              # 检查依赖一致性
pip list --outdated    # 可升级包
pip show <pkg>         # 包信息
```

## 31.9 虚拟环境 vs 系统 Python

- 始终在虚拟环境中工作
- 避免污染系统 Python
- 项目根目录放 `venv/`，加入 `.gitignore`

## 31.10 .gitignore

```
venv/
__pycache__/
*.pyc
```

## 小结

- 每个项目一个 venv
- 用 pip 管理依赖
- requirements.txt 锁定版本
- 第三方库用 pip install
