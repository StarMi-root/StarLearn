# 36. 上下文管理器

## 学习目标

- 理解 with 语句
- 实现自定义上下文管理器
- 掌握 contextlib

## 36.1 with 语法

```python
with open("data.txt") as f:
    data = f.read()
# 自动关闭
```

## 36.2 多个资源

```python
with open("a.txt") as fa, open("b.txt") as fb:
    a = fa.read()
    b = fb.read()
```

## 36.3 实现上下文管理器

### 类形式

```python
class Managed:
    def __init__(self, resource):
        self.resource = resource

    def __enter__(self):
        print("acquired")
        return self.resource

    def __exit__(self, exc_type, exc_val, exc_tb):
        print("released")
        return False  # 不吞异常
```

### 生成器形式

```python
from contextlib import contextmanager

@contextmanager
def managed(resource):
    print("acquired")
    try:
        yield resource
    finally:
        print("released")
```

## 36.4 contextlib 工具

```python
from contextlib import contextmanager, closing, suppress

# 关闭资源
with closing(open("data.txt")) as f:
    data = f.read()

# 忽略异常
with suppress(FileNotFoundError):
    open("missing.txt")
```

## 36.5 常见应用

```python
# 数据库连接
class DB:
    def connect(self): ...
    def close(self): ...

class DBContext:
    def __init__(self, db):
        self.db = db
    def __enter__(self):
        self.db.connect()
        return self.db
    def __exit__(self, *exc):
        self.db.close()
        return False

with DBContext(MyDB()) as db:
    db.query("SELECT 1")
```

## 36.6 退出值

```python
def __exit__(self, exc_type, exc_val, exc_tb):
    if exc_type is None:
        return False
    print(f"handling {exc_type.__name__}")
    return True  # 吞掉异常
```

## 36.7 嵌套与组合

```python
with A(), B(), C():
    ...
```

按顺序 enter，按逆序 exit。

## 36.8 何时用

- 资源管理（文件、连接、锁）
- 临时状态修改
- 异常处理边界

## 小结

- with 保证资源释放
- `__enter__` / `__exit__` 实现
- `@contextmanager` 简化
- 嵌套按逆序退出
