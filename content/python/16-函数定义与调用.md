# 第 4 章 函数

# 16. 函数定义与调用

## 学习目标

- 学会 def 定义函数
- 理解参数与返回值
- 掌握文档字符串
- 了解作用域基础

## 16.1 基本语法

```python
def greet(name):
    """向某人打招呼。"""
    print(f"Hello, {name}!")

greet("Alice")
```

## 16.2 参数

### 位置参数

```python
def add(a, b):
    return a + b
```

### 默认值

```python
def power(base, exp=2):
    return base ** exp

power(3)       # 9
power(3, 3)    # 27
```

### 关键字参数

```python
def power(base, exp):
    return base ** exp

power(base=3, exp=4)
```

## 16.3 返回值

```python
def classify(x):
    if x > 0:
        return "positive"
    elif x < 0:
        return "negative"
    return "zero"
```

没有 return 或 return 不带值，返回 None。

## 16.4 多返回值

```python
def divmod_(a, b):
    return a // b, a % b

q, r = divmod_(17, 5)
```

实际是返回一个元组。

## 16.5 文档字符串（docstring）

```python
def calculate_area(radius):
    """计算圆的面积。

    Args:
        radius: 半径（必须为正数）。

    Returns:
        圆的面积。

    Raises:
        ValueError: 当 radius <= 0 时。
    """
    if radius <= 0:
        raise ValueError("radius must be positive")
    return 3.14159 * radius ** 2
```

用 `help(calculate_area)` 查看。

## 16.6 函数是一等对象

```python
def add(a, b):
    return a + b

f = add
f(2, 3)  # 5

# 可作为参数
def apply(func, x):
    return func(x)

apply(add, 10)  # 不对，add 需要两个参数
```

## 16.7 作用域（初步）

```python
x = "global"

def show():
    print(x)  # 读取全局 x

def modify():
    # x = "local"  # 这样就是局部变量
    print(x)       # 仍读全局
```

## 16.8 函数默认值陷阱

```python
# 差
def f(lst=[]):
    lst.append(1)
    return lst

f()  # [1]
f()  # [1, 1]  共享同一对象！

# 好
def f(lst=None):
    if lst is None:
        lst = []
    lst.append(1)
    return lst
```

## 小结

- 默认参数只求值一次
- 用 docstring 记录 API
- 多返回值是元组
- 函数可传递、可存储
