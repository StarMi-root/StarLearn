# 第 5 章 面向对象编程

# 26. 抽象类与接口

## 学习目标

- 掌握 abc 模块
- 学会定义抽象方法
- 理解抽象类的意义

## 26.1 基本用法

```python
from abc import ABC, abstractmethod

class Shape(ABC):
    @abstractmethod
    def area(self):
        """计算面积，子类必须实现。"""

    def describe(self):
        return f"Shape with area {self.area()}"

class Circle(Shape):
    def __init__(self, r):
        self.r = r
    def area(self):
        return 3.14159 * self.r ** 2

class Square(Shape):
    def __init__(self, s):
        self.s = s
    def area(self):
        return self.s ** 2

# 不能实例化抽象类
s = Shape()  # TypeError: Can't instantiate abstract class Shape
```

## 26.2 抽象属性

```python
class Database(ABC):
    @property
    @abstractmethod
    def connection(self):
        ...

class Postgres(Database):
    def __init__(self, dsn):
        self.dsn = dsn

    @property
    def connection(self):
        import psycopg2
        return psycopg2.connect(self.dsn)
```

## 26.3 注册虚拟子类

```python
class Animal(ABC):
    @abstractmethod
    def speak(self): ...

# 不需要继承，也可注册
Animal.register(Monkey)  # Monkey 没有定义 speak，但 isinstance 返回 True
```

## 26.4 何时用抽象类

| 场景 | 推荐 |
|------|------|
| 明确契约（必须实现某些方法） | 抽象类 |
| 鸭子类型足够 | 不写抽象类 |
| 多个实现共享部分代码 | 抽象类 |

## 26.5 接口 vs 抽象类

- **接口**：纯抽象，无实现
- **抽象类**：可包含具体方法

Python 的 ABC 可以两者混合。

## 26.6 与 Protocol 对比

Python 3.8+ 有 `typing.Protocol`，更轻量（不需要继承）：

```python
from typing import Protocol

class Drawable(Protocol):
    def draw(self): ...

# 任何有 draw 方法的对象都符合
```

详见第 48 节。

## 小结

- 抽象类强制契约
- @abstractmethod 标记必须实现的方法
- 虚拟子类注册灵活
- 简单场景用 Protocol 更轻量
