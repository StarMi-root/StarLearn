# 第 1 章 入门基础

# 1. 环境与安装

## 学习目标

- 在你的操作系统上安装 Python
- 学会使用终端（Terminal / 命令行）
- 运行你的第一个 Python 程序

## 1.1 检查是否已安装

打开终端（macOS/Linux 用 Terminal，Windows 用 PowerShell 或 cmd），输入：

```bash
python --version
```

如果输出了类似 `Python 3.11.5`，说明已安装。否则需要安装。

## 1.2 安装 Python

### macOS / Linux

大多数 Linux 发行版自带 Python 3。macOS 可以用 Homebrew：

```bash
brew install python
```

### Windows

1. 访问 https://www.python.org/downloads/ 下载最新稳定版。
2. 运行安装程序，**务必勾选 "Add Python to PATH"**。
3. 安装完成后打开新的终端窗口验证。

## 1.3 运行第一个程序

创建文件 `hello.py`：

```python
print("Hello, World!")
```

在终端执行：

```bash
python hello.py
```

输出：

```
Hello, World!
```

## 1.4 交互式解释器

直接输入 `python` 进入交互式环境：

```
$ python
>>> 1 + 1
2
>>> print("hi")
hi
>>> exit()
```

适合快速试验表达式。

## 1.5 推荐编辑器

- **VS Code**（免费）+ Python 扩展
- **PyCharm**（社区版免费）
- **Jupyter Notebook**（适合数据科学）

## 1.6 验证安装

```bash
python -c "import sys; print(sys.version)"
```

应该输出版本号和解释器信息。

## 小结

- 安装 Python 时记得勾选 "Add Python to PATH"
- 用 `python 文件名.py` 运行脚本
- 直接 `python` 进入交互模式
