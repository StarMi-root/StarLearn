# 第 3 章 数据结构

# 13. 集合

## 学习目标

- 理解集合去重与集合运算
- 掌握 add、remove、discard
- 学会交集、并集、差集、对称差

## 13.1 创建

```python
s = {1, 2, 3}
s = set("hello")  # {'h', 'e', 'l', 'o'}
s = set()         # 空集合（注意 {} 是空字典）
```

## 13.2 基本操作

```python
s = {1, 2, 3}
3 in s        # True
s.add(4)      # 添加（已存在不报错）
s.discard(4)  # 删除（不存在不报错）
s.remove(5)   # 删除（不存在 KeyError）
```

## 13.3 集合运算

```python
a = {1, 2, 3, 4}
b = {3, 4, 5, 6}

a | b   # 并集 {1,2,3,4,5,6}
a & b   # 交集 {3,4}
a - b   # 差集 {1,2}
a ^ b   # 对称差 {1,2,5,6}
```

方法形式：

```python
a.union(b)
a.intersection(b)
a.difference(b)
a.symmetric_difference(b)
```

## 13.4 子集与超集

```python
a = {1, 2}
b = {1, 2, 3}
a.issubset(b)    # True
b.issuperset(a)   # True
```

## 13.5 实际用法

### 去重

```python
unique = list(set([1, 2, 2, 3, 3, 3]))
# [1, 2, 3]（顺序不保证）
```

### 查找共同元素

```python
friends_a = {"Alice", "Bob", "Carol"}
friends_b = {"Bob", "Dave"}
mutual = friends_a & friends_b
# {"Bob"}
```

### 差集找出缺失

```python
expected = {"a", "b", "c", "d"}
got = {"a", "c"}
missing = expected - got
# {"b", "d"}
```

## 13.6 陷阱

```python
s = {1, 2, 3}
s[0]  # TypeError: 'set' object is not subscriptable
```

集合不支持索引，只能遍历。

## 13.7 列表 vs 集合

| 特性 | 列表 | 集合 |
|------|------|------|
| 有序 | 是 | 否 |
| 重复 | 允许 | 不允许 |
| 索引 | 支持 | 不支持 |
| 查找 | O(n) | O(1) |

## 小结

- 集合自动去重
- 查找成员用集合（O(1)）
- 集合运算适合比较两组数据
- 空集用 `set()`，不用 `{}`
