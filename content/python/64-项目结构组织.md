# 第 14 章 工程化与最佳实践

# 64. 项目结构组织

## 学习目标

- 掌握常见项目结构
- 理解 __init__.py 作用
- 学会组织代码

## 64.1 小项目（脚本）

```
project/
  main.py
  utils.py
  requirements.txt
```

## 64.2 中等项目（包）

```
project/
  src/
    mypackage/
      __init__.py
      module_a.py
      module_b.py
      subpackage/
        __init__.py
        module_c.py
  tests/
    test_module_a.py
    test_module_b.py
  main.py
  requirements.txt
  pyproject.toml
```

## 64.3 大项目（src 布局）

```
project/
  src/
    mypackage/
      __init__.py
      core/
      api/
      db/
  tests/
  scripts/
  docs/
  pyproject.toml
```

src 布局避免模块意外导入。

## 64.4 __init__.py 作用

```python
# mypackage/__init__.py
__version__ = "1.0.0"

from .module_a import ClassA
from .module_b import ClassB

__all__ = ["ClassA", "ClassB"]
```

## 64.5 模块组织原则

- **高内聚**：相关功能同模块
- **低耦合**：模块间依赖最小
- **单一职责**：一个模块做一件事

## 64.6 目录命名

```
mypackage/
  models/       数据模型
  services/     业务逻辑
  api/          API 端点
  utils/        工具函数
  config/       配置
  tests/        测试
```

## 64.7 入口点

```python
# main.py
from mypackage import run

if __name__ == "__main__":
    run()
```
