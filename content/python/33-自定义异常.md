# 第 7 章 异常与错误处理

# 33. 自定义异常

## 学习目标

- 学会定义异常类
- 设计异常层级
- 掌握异常消息

## 33.1 基本用法

```python
class AppError(Exception):
    """应用基础异常。"""
    pass

class ConfigError(AppError):
    """配置错误。"""
    def __init__(self, key, reason=None):
        self.key = key
        self.reason = reason
        super().__init__(f"Config error: {key}: {reason or 'invalid'}")

class DataError(AppError):
    """数据错误。"""
```

## 33.2 抛出与捕获

```python
def load_config(path):
    if not os.path.exists(path):
        raise ConfigError("path", "file not found")
    ...

try:
    load_config("missing.yaml")
except ConfigError as e:
    print(f"Config failed: {e.key}: {e.reason}")
```

## 33.3 携带上下文

```python
class ValidationError(Exception):
    def __init__(self, field, value, expected):
        self.field = field
        self.value = value
        self.expected = expected
        super().__init__(
            f"Field '{field}': got {value!r}, expected {expected}"
        )

raise ValidationError("age", -1, "non-negative int")
```

## 33.4 异常层级设计

```
Exception
└── AppError            # 应用根异常
    ├── ConfigError     # 配置相关
    ├── DataError       # 数据相关
    │   ├── ParseError
    │   └── ValidationError
    └── NetworkError    # 网络相关
```

好处：调用者可以只捕获 `AppError` 兜底，或精确捕获子类。

## 33.5 保留原始异常

```python
try:
    data = json.loads(text)
except json.JSONDecodeError as e:
    raise ValueError(f"bad JSON: {text!r}") from e
```

`from e` 保留原始异常链。

## 33.6 静默异常

```python
try:
    result = risky()
except SomeError:
    logging.warning("risky failed, using default")
    result = default
```

## 33.7 异常 vs 返回值

| 场景 | 推荐 |
|------|------|
| 罕见错误 | 异常 |
| 常见分支 | 返回值（Optional） |
| 数据校验 | 异常或返回 None |

## 33.8 常见错误消息

```python
# 差
raise ValueError("bad")

# 好
raise ValueError(f"age must be >= 0, got {age}")
```

## 小结

- 自定义异常继承 Exception
- 设计清晰的层级
- 异常消息要具体
- 用 `from e` 保留异常链
