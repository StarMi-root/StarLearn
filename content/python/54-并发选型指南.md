# 第 10 章 并发与异步

# 54. 并发选型指南

## 学习目标

- 根据任务类型选并发模型
- 理解权衡
- 学会混合策略

## 54.1 任务分类

| 类型 | 特征 | 推荐 |
|------|------|------|
| CPU 密集 | 大量计算 | 多进程 |
| I/O 密集 | 等待外部 | 多线程 / asyncio |
| 混合 | 两者都有 | 进程 + 线程 |

## 54.2 选型决策树

```
CPU 密集？
  是 → 多进程
  否 → I/O 密集？
        是 → 连接数大？
              是 → asyncio
              否 → 多线程
        否 → 顺序执行
```

## 54.3 多进程

```python
from multiprocessing import Pool
with Pool(4) as p:
    results = p.map(cpu_heavy, data)
```

- 突破 GIL
- 数据序列化开销
- 适合 CPU 密集

## 54.4 多线程

```python
from concurrent.futures import ThreadPoolExecutor
with ThreadPoolExecutor(8) as pool:
    results = [f.result() for f in pool.map(network_call, urls)]
```

- 共享内存
- GIL 限制 CPU
- 适合 I/O 密集

## 54.5 asyncio

```python
import asyncio
async def main():
    await asyncio.gather(*[fetch(u) for u in urls])
asyncio.run(main())
```

- 单线程事件循环
- 高并发 I/O
- 大量连接

## 54.6 混合策略

- 多进程处理 CPU
- 每进程内用 asyncio 处理 I/O

```python
import multiprocessing as mp
import asyncio

def worker(data):
    loop = asyncio.new_event_loop()
    asyncio.set_event_loop(loop)
    loop.run_until_complete(process(data))
    loop.close()
```

## 54.7 性能指标

- **吞吐**：每秒处理量
- **延迟**：单任务耗时
- **资源**：内存、CPU

## 54.8 常见场景

### 爬虫

- 高并发 → asyncio + aiohttp
- 解析 CPU → 多进程

### 数据管道

- ETL 多步 → 顺序
- 并发下载 → 多线程/asyncio

### Web 服务

- 同步 → 多线程
- 异步 → asyncio + FastAPI

## 54.9 调试

- 死锁：线程
- 竞态条件：共享状态
- 协程未 await：逻辑错误

## 54.10 工具

- `multiprocessing`：进程
- `threading`：线程
- `asyncio`：协程
- `concurrent.futures`：统一 API

## 54.11 最佳实践

- 先顺序，再并发
- 共享状态最小化
- 锁粒度小
- 监控性能

## 小结

- CPU 密集 → 多进程
- I/O 密集 → 多线程/asyncio
- 混合策略
- 先简单再优化
