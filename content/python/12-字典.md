# 第 3 章 数据结构

# 12. 字典

## 学习目标

- 掌握字典的键值对操作
- 学会 get、setdefault、update
- 理解嵌套字典
- 避免键陷阱

## 12.1 创建与访问

```python
d = {"name": "Alice", "age": 30}
d["name"]        # "Alice"
d["city"]        # KeyError

# 安全访问
d.get("city")          # None
d.get("city", "NYC")   # "NYC"
```

## 12.2 增删改

```python
d["city"] = "NYC"     # 添加或修改
d["hobby"] = "coding"
del d["age"]          # 删除
d.pop("age", None)    # 安全删除
```

## 12.3 常用方法

```python
d.keys()   # dict_keys 视图
d.values() # dict_values 视图
d.items()  # dict_items 视图

# 迭代
for k, v in d.items():
    print(k, v)

# 合并（Python 3.9+）
d1 = {"a": 1}
d2 = {"b": 2}
d1 | d2          # {"a": 1, "b": 2}
d1 |= d2         # 原地合并

# 更新
d.update({"a": 10, "c": 30})
d.update(x=5)    # 等价于 d.update({"x": 5})
```

## 12.4 get vs []

```python
d = {"a": 1}
d["a"]       # 不存在时 KeyError
d.get("a")   # 不存在时 None（或指定默认值）
```

## 12.5 setdefault

```python
d = {}
d.setdefault("count", 0)
d["count"] += 1
```

等价于：

```python
if "count" not in d:
    d["count"] = 0
d["count"] += 1
```

## 12.6 嵌套字典

```python
db = {
    "users": [
        {"name": "Alice", "age": 30},
        {"name": "Bob", "age": 25}
    ]
}
print(db["users"][0]["name"])  # "Alice"
```

## 12.7 陷阱

### 可变键

```python
d = {[1, 2]: "x"}  # TypeError: unhashable type: 'list'
d = {(1, 2): "x"}  # OK
```

### 键的"修改"

```python
d = {"a": 1}
key = "a"
key = "b"
d[key] = 2  # 添加新键 "b"
```

### 字典视图是动态的

```python
d = {"a": 1, "b": 2}
keys = d.keys()
d["c"] = 3
print(keys)  # dict_keys(['a', 'b', 'c'])（实时反映）
```

## 12.8 字典推导式

```python
squares = {i: i**2 for i in range(5)}
# {0: 0, 1: 1, 2: 4, 3: 9, 4: 16}

filtered = {k: v for k, v in d.items() if v > 0}
```

## 小结

- 字典 O(1) 查找
- 用 `.get()` 避免 KeyError
- 键必须可哈希
- 嵌套字典用 `[]` 链式访问
