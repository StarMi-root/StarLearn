# 20. 装饰器

## 20.1 装饰器是什么

装饰器 = 接受函数、返回函数的函数。

```python
def my_decorator(func):
    def wrapper(*args, **kwargs):
        print("before")
        result = func(*args, **kwargs)
        print("after")
        return result
    return wrapper

@my_decorator
def say_hello():
    print("Hello")

say_hello()
# before
# Hello
# after
```

`@my_decorator` 等价于 `say_hello = my_decorator(say_hello)`。

## 20.2 functools.wraps

保留原函数元信息：

```python
import functools

def my_decorator(func):
    @functools.wraps(func)
    def wrapper(*args, **kwargs):
        return func(*args, **kwargs)
    return wrapper

@my_decorator
def greet(name):
    """Greet someone."""
    print(f"Hi {name}")

print(greet.__name__)   # "greet"（不是 "wrapper"）
print(greet.__doc__)    # "Greet someone."
```

## 20.3 实际例子

### 计时

```python
import time, functools

def timer(func):
    @functools.wraps(func)
    def wrapper(*args, **kwargs):
        start = time.perf_counter()
        result = func(*args, **kwargs)
        elapsed = time.perf_counter() - start
        print(f"{func.__name__} took {elapsed:.4f}s")
        return result
    return wrapper

@timer
def slow():
    time.sleep(1)
```

### 重试

```python
import time

def retry(times=3, delay=1):
    def decorator(func):
        @functools.wraps(func)
        def wrapper(*args, **kwargs):
            for attempt in range(times):
                try:
                    return func(*args, **kwargs)
                except Exception as e:
                    if attempt == times - 1:
                        raise
                    time.sleep(delay)
        return wrapper
    return decorator

@retry(times=5, delay=0.5)
def fetch():
    ...
```

## 20.4 类装饰器

```python
class Counter:
    def __init__(self, func):
        self.func = func
        self.calls = 0

    def __call__(self, *args, **kwargs):
        self.calls += 1
        return self.func(*args, **kwargs)

@Counter
def hello():
    print("hi")
```

## 20.5 参数化装饰器

参数化装饰器接受 3 层：参数 → 函数 → 调用。

```python
def log(level):
    def decorator(func):
        @functools.wraps(func)
        def wrapper(*args, **kwargs):
            print(f"[{level}] calling {func.__name__}")
            return func(*args, **kwargs)
        return wrapper
    return decorator

@log("DEBUG")
def f():
    ...
```

## 小结

- 装饰器是闭包 + 函数一等对象的应用
- 永远加 `@functools.wraps`
- 参数化装饰器三层嵌套
- 类装饰器用 `__call__`
