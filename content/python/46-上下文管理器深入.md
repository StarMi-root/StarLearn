## 46.1 contextmanager

```python
from contextlib import contextmanager

@contextmanager
def managed_resource(name):
    print(f"open {name}")
    try:
        yield name
    finally:
        print(f"close {name}")

with managed_resource("file") as r:
    print(r)  # file
```

## 46.2 asynccontextmanager

```python
from contextlib import asynccontextmanager

@asynccontextmanager
async def db_conn():
    conn = await connect()
    try:
        yield conn
    finally:
        await conn.close()

async def main():
    async with db_conn() as conn:
        await conn.query("SELECT 1")
```

## 46.3 退出值语义

```python
def __exit__(self, exc_type, exc_val, exc_tb):
    if exc_type is None:
        return False
    print(f"handling {exc_type.__name__}")
    return True  # 吞掉异常
```

- 返回 `True`：吞掉异常
- 返回 `False`/`None`：异常继续传播

## 46.4 suppress

```python
from contextlib import suppress

with suppress(FileNotFoundError):
    open("missing.txt")
# 不报错
```

## 46.5 redirect_stdout

```python
from contextlib import redirect_stdout
import io

with redirect_stdout(io.StringIO()) as f:
    print("captured")
print(f.getvalue())  # "captured\n"
```

## 46.6 嵌套组合

```python
@contextmanager
def cm_a():
    yield "A"

@contextmanager
def cm_b():
    yield "B"

# 组合
@contextmanager
def combined():
    with cm_a() as a, cm_b() as b:
        yield (a, b)
```

## 46.7 类形式 vs 生成器

```python
# 类
class MyCM:
    def __enter__(self):
        ...
    def __exit__(self, *exc):
        ...

# 生成器（更简洁）
@contextmanager
def my_cm():
    ...
    yield
    ...
```

## 46.8 数据库事务

```python
@contextmanager
def transaction(conn):
    try:
        yield conn
        conn.commit()
    except:
        conn.rollback()
        raise

with transaction(conn) as c:
    c.execute("INSERT ...")
```
