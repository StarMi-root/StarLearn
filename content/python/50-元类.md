# 第 9 章 进阶特性

# 50. 元类

## 学习目标

- 理解元类
- 掌握 type()
- 学会自定义元类

## 50.1 类是对象

```python
class MyClass:
    pass

type(MyClass)  # <class 'type'>
```

`type` 是类的类（元类）。

## 50.2 type() 的两种用法

```python
# 查看类型
type(42)  # <class 'int'>

# 动态创建类
MyClass = type("MyClass", (object,), {"x": 1})
m = MyClass()
print(m.x)  # 1
```

三个参数：类名、基类、属性字典。

## 50.3 自定义元类

```python
class Meta(type):
    def __new__(mcs, name, bases, namespace):
        print(f"creating {name}")
        cls = super().__new__(mcs, name, bases, namespace)
        return cls

class MyClass(metaclass=Meta):
    pass
# 输出：creating MyClass
```

## 50.4 实际例子

### 注册所有实例

```python
class RegistryMeta(type):
    def __init__(cls, name, bases, namespace):
        super().__init__(name, bases, namespace)
        cls._instances = []

    def __call__(cls, *args, **kwargs):
        instance = super().__call__(*args, **kwargs)
        cls._instances.append(instance)
        return instance

class Widget(metaclass=RegistryMeta):
    def __init__(self, name):
        self.name = name

w1 = Widget("a")
w2 = Widget("b")
print(Widget._instances)  # [w1, w2]
```

### 单例

```python
class SingletonMeta(type):
    _instances = {}

    def __call__(cls, *args, **kwargs):
        if cls not in cls._instances:
            cls._instances[cls] = super().__call__(*args, **kwargs)
        return cls._instances[cls]

class App(metaclass=SingletonMeta):
    pass

a1 = App()
a2 = App()
print(a1 is a2)  # True
```

## 50.5 元类继承

```python
class BaseMeta(type):
    ...

class ChildMeta(BaseMeta):
    ...

class MyClass(metaclass=ChildMeta):
    ...
```

只能一个元类（Python 3 用 MRO）。

## 50.6 何时用元类

- ORM（Django）
- 框架注册
- 单例
- 自动 API 生成

## 50.7 何时不用

- 99% 的场景用装饰器
- 元类增加复杂度
- 调试困难

## 50.8 注意事项

- 元类作用于**类**，不是实例
- `__new__` 在 `__init__` 之前
- 避免过多嵌套

## 小结

- 元类是类的类
- type() 动态创建类
- 单例、注册用元类
- 复杂，谨慎使用
