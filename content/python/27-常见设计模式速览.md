## 27.1 单例模式

```python
class Singleton:
    _instance = None

    def __new__(cls, *args, **kwargs):
        if cls._instance is None:
            cls._instance = super().__new__(cls)
        return cls._instance

# 装饰器形式
def singleton(cls):
    instances = {}
    def get_instance(*args, **kwargs):
        if cls not in instances:
            instances[cls] = cls(*args, **kwargs)
        return instances[cls]
    return get_instance
```

## 27.2 工厂模式

```python
class Button:
    def render(self): ...

class HTMLButton(Button):
    def render(self):
        return "<button>...</button>"

class QtButton(Button):
    def render(self):
        ...

def create_button(kind):
    if kind == "html":
        return HTMLButton()
    elif kind == "qt":
        return QtButton()
```

Python 中常简化为函数或 classmethod。

## 27.3 观察者模式

```python
class Event:
    def __init__(self):
        self._subs = []

    def subscribe(self, callback):
        self._subs.append(callback)

    def publish(self, data):
        for cb in self._subs:
            cb(data)

# 使用
on_data = Event()
on_data.subscribe(lambda d: print("got", d))
on_data.publish(42)
```

第三方库：`blinker`、`pyee`。

## 27.4 策略模式

```python
class Strategy:
    def apply(self, x): ...

class NoDiscount(Strategy):
    def apply(self, x): return x

class TenPercentOff(Strategy):
    def apply(self, x): return x * 0.9

class Order:
    def __init__(self, amount, strategy: Strategy):
        self.amount = amount
        self.strategy = strategy

    def price(self):
        return self.strategy.apply(self.amount)
```

Python 中常用函数代替策略对象。

## 27.5 迭代器模式

```python
class Fibonacci:
    def __init__(self, max_terms=10):
        self.max = max_terms

    def __iter__(self):
        a, b = 0, 1
        for _ in range(self.max):
            yield a
            a, b = b, a + b
```

## 27.7 推荐库

- **attrs / dataclasses**：数据类
- **functools**：装饰器、LRU 缓存
- **itertools**：迭代器工具
