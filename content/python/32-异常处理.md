# 第 7 章 异常与错误处理

# 32. 异常处理

## 学习目标

- 掌握 try/except/else/finally
- 学会 raise 自定义异常
- 理解异常层级
- 避免吞异常

## 32.1 基本语法

```python
try:
    x = 1 / 0
except ZeroDivisionError:
    print("除零错误")
```

## 32.2 捕获多种异常

```python
try:
    ...
except (ValueError, TypeError) as e:
    print(f"错误: {e}")
except Exception as e:
    print(f"其他错误: {e}")
```

## 32.3 else 与 finally

```python
try:
    f = open("data.txt")
except FileNotFoundError:
    print("文件不存在")
else:
    # 仅在 try 没异常时执行
    data = f.read()
finally:
    # 无论是否异常都执行
    print("cleanup")
```

## 32.4 抛出异常

```python
def set_age(age):
    if age < 0:
        raise ValueError("age must be non-negative")
    ...
```

## 32.5 异常层级

```
BaseException
  ├── Exception
  │     ├── ValueError
  │     ├── TypeError
  │     ├── KeyError
  │     ├── IndexError
  │     ├── OSError
  │     │     └── FileNotFoundError
  │     └── ...
  ├── SystemExit
  ├── KeyboardInterrupt
  └── GeneratorExit
```

## 32.6 常见异常

| 异常 | 场景 |
|------|------|
| ValueError | 值不合法 |
| TypeError | 类型错误 |
| KeyError | 字典键不存在 |
| IndexError | 索引越界 |
| AttributeError | 属性不存在 |
| FileNotFoundError | 文件不存在 |
| StopIteration | 迭代器耗尽 |
| RuntimeError | 运行时错误 |

## 32.7 反模式

```python
# 差：吞异常
try:
    x = int(input())
except:
    pass

# 好：捕获具体异常
try:
    x = int(input())
except ValueError:
    print("请输入数字")
```

## 32.8 上下文管理器中处理异常

```python
try:
    with open("data.txt") as f:
        data = f.read()
except FileNotFoundError:
    data = ""
```

## 32.9 记录异常

```python
import traceback

try:
    ...
except Exception as e:
    traceback.print_exc()
    # 或
    logging.exception("出错了")
```

## 32.10 异常 vs 断言

- 异常：预期可能发生的错误
- 断言（assert）：内部不变量

```python
assert n > 0, "n must be positive"
```

## 小结

- 捕获具体异常，不吞异常
- finally 用于清理
- 用 raise 抛出有意义的异常
- 异常层级帮你精确捕获
