# 第 10 章 并发与异步

# 51. 多进程

## 学习目标

- 理解进程 vs 线程
- 掌握 multiprocessing
- 学会进程池

## 51.1 进程 vs 线程

| 特性 | 进程 | 线程 |
|------|------|------|
| 内存 | 独立 | 共享 |
| 通信 | IPC | 共享变量 |
| 开销 | 大 | 小 |
| GIL | 不受影响 | 受 GIL 限制 |

## 51.2 基本用法

```python
import multiprocessing as mp

def worker(x):
    return x * x

if __name__ == "__main__":
    p = mp.Process(target=worker, args=(5,))
    p.start()
    p.join()
```

## 51.3 进程池

```python
from multiprocessing import Pool

def square(x):
    return x * x

if __name__ == "__main__":
    with Pool(4) as p:
        results = p.map(square, range(10))
    print(results)
```

## 51.4 队列通信

```python
import multiprocessing as mp

def producer(q):
    for i in range(5):
        q.put(i)

def consumer(q):
    while True:
        item = q.get()
        if item is None:
            break
        print(item)

if __name__ == "__main__":
    q = mp.Queue()
    p1 = mp.Process(target=producer, args=(q,))
    p2 = mp.Process(target=consumer, args=(q,))
    p1.start()
    p2.start()
    p1.join()
    q.put(None)  # 信号
    p2.join()
```

## 51.5 共享内存

```python
from multiprocessing import Value, Lock

counter = Value("i", 0)
lock = Lock()

def increment():
    for _ in range(1000):
        with lock:
            counter.value += 1
```

## 51.6 进程 vs 线程选择

- **CPU 密集** → 多进程
- **I/O 密集** → 多线程或 asyncio
- **突破 GIL** → 多进程

## 51.7 常见陷阱

```python
# Windows 必须 if __name__ == "__main__"
# 否则进程会递归创建
if __name__ == "__main__":
    ...
```

## 51.8 性能考虑

- 进程创建开销大
- 数据传递需序列化
- 小任务用线程或协程

## 51.9 并发模型

- `Process`：手动
- `Pool`：进程池
- `Queue`：通信
- `Manager`：共享对象

## 51.10 最佳实践

- 任务量大用进程池
- 进程间用 Queue 通信
- 避免共享可变状态
- Windows 注意 `__main__`

## 小结

- 多进程突破 GIL
- 进程池管理并发
- Queue 通信
- CPU 密集用多进程
