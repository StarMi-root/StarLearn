# 第 3 章 数据结构

# 9. 字符串深入

## 学习目标

- 掌握切片语法
- 学会常用字符串方法
- 理解字符串不可变性
- 避免常见陷阱

## 9.1 切片

```python
s = "hello world"
s[0]      # 'h'
s[-1]     # 'd'
s[0:5]    # 'hello'
s[6:]     # 'world'
s[:5]     # 'hello'
s[::2]    # 'hllo'（步长2）
s[::-1]   # 'dlrow olleh'（反转）
```

## 9.2 常用方法

```python
"Hello World"
.upper()           # "HELLO WORLD"
.lower()          # "hello world"
.title()          # "Hello World"
.strip()          # 去首尾空白
.lstrip() / .rstrip()
.replace("o", "0") # "Hell0 W0rld"
.split(" ")       # ['Hello', 'World']
.split()          # 按任意空白切分
.join(["a", "b"]) # "aXb"（X 是分隔符）
.count("l")       # 2
.find("World")     # 6
.startswith("Hello")  # True
```

## 9.3 不可变性

字符串不可变，每次"修改"都创建新对象：

```python
s = "hello"
s[0] = "H"  # TypeError: 'str' object does not support item assignment

# 需要拼接时
s = "Hello" + s[1:]
# 或更优雅
s = "H" + s[1:]
```

大量拼接用 join：

```python
# 差（O(n²)）
result = ""
for word in words:
    result += word + " "

# 好（O(n)）
result = " ".join(words)
```

## 9.4 字符串方法速查

| 方法 | 作用 |
|------|------|
| `str.split(sep)` | 切分 |
| `str.join(iter)` | 连接 |
| `str.strip(chars)` | 去首尾字符 |
| `str.replace(a, b)` | 替换 |
| `str.find(s)` | 查找（-1 表示没找到） |
| `str.count(s)` | 计数 |
| `str.startswith(s)` | 前缀 |
| `str.endswith(s)` | 后缀 |
| `str.isalpha()` | 全字母 |
| `str.isdigit()` | 全数字 |
| `str.isalnum()` | 字母数字 |
| `str.title()` | 首字母大写 |

## 9.5 原始字符串

```python
r"\n"      # 保留反斜杠
r"C:\path" # Windows 路径
```

## 9.6 编码与解码

```python
s = "你好"
b = s.encode("utf-8")   # b'\xe4\xbd\xa0\xe5\xa5\xbd'
s = b.decode("utf-8")    # "你好"
```

## 9.7 字符串比较

```python
"abc" == "abc"   # True（值比较）
"abc" is "abc"   # 不确定（驻留机制），不要依赖
"abc" < "abd"    # True（字典序）
```

## 小结

- 切片 `s[start:stop:step]` 非常强大
- 不可变 → 拼接用 join
- 用 `in` 判断子串
- 字符串方法是纯函数，不修改原串
