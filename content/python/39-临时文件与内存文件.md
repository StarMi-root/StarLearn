# 39. 临时文件与内存文件

## 学习目标

- 掌握 tempfile
- 学会 io.StringIO / BytesIO
- 理解场景选择

## 39.1 tempfile 模块

### 临时文件

```python
import tempfile

with tempfile.NamedTemporaryFile(mode="w", delete=False, suffix=".txt") as f:
    f.write("data")
    tmp_path = f.name

# 使用 tmp_path
# 完成后
import os
os.unlink(tmp_path)
```

### 临时目录

```python
with tempfile.TemporaryDirectory() as tmpdir:
    print(tmpdir)  # 自动创建，退出时删除
    Path(tmpdir, "file.txt").write_text("x")
```

## 39.2 io.StringIO

内存中的文本流：

```python
from io import StringIO

sio = StringIO()
sio.write("hello\n")
sio.write("world\n")
sio.seek(0)
print(sio.read())
# hello
# world

# 或
text = "".join(["a", "b", "c"])
```

## 39.3 io.BytesIO

内存中的二进制流：

```python
from io import BytesIO

bio = BytesIO(b"hello")
bio.read()  # b"hello"

bio = BytesIO()
bio.write(b"data")
bio.seek(0)
bio.getvalue()  # b"data"
```

## 39.4 场景对比

| 需求 | 工具 |
|------|------|
| 需要磁盘持久化 | tempfile |
| 纯内存处理 | io.StringIO/BytesIO |
| 临时工作目录 | tempfile.TemporaryDirectory |
| 测试 mock | io 类 |

## 39.5 与 open 兼容

```python
from io import StringIO
import json

data = {"key": "value"}
sio = StringIO(json.dumps(data))
obj = json.load(sio)  # 任何接受 file-like 的 API 都能用
```

## 39.6 临时文件陷阱

```python
# Linux 上打开已删除的文件
f = open("/tmp/x", "w")
os.unlink("/tmp/x")  # f 仍可用，关闭后才真正消失

# Windows 上临时文件不能重复打开
# 用 delete=False 手动删除
```

## 39.7 shutil 相关

```python
import shutil
shutil.copyfile("a.txt", "b.txt")
shutil.copytree("dir1", "dir2")
shutil.move("a.txt", "b.txt")
shutil.rmtree("dir")  # 删除目录树
```

## 39.8 清理策略

- 用 with 自动清理
- tempfile.TemporaryDirectory 退出时删除
- 显式 unlink 要放在 finally

## 小结

- tempfile 用于磁盘临时文件
- io.StringIO/BytesIO 用于内存流
- 临时目录自动清理
- 与 file-like API 兼容
