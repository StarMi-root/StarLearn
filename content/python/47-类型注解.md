# 第 9 章 进阶特性

# 47. 类型注解

## 学习目标

- 掌握内置类型注解
- 学会 typing 模块
- 理解类型检查工具

## 47.1 基本注解

```python
def add(a: int, b: int) -> int:
    return a + b

name: str = "Alice"
age: int = 30
```

## 47.2 内置容器

```python
from typing import List, Dict, Set, Tuple

items: List[int] = [1, 2, 3]
config: Dict[str, int] = {"a": 1}
```

Python 3.9+ 可直接用内置：

```python
items: list[int] = [1, 2, 3]
config: dict[str, int] = {"a": 1}
```

## 47.3 Optional 与 Union

```python
from typing import Optional, Union

def find(name: str) -> Optional[str]:
    ...

# Python 3.10+
def find(name: str) -> str | None:
    ...
```

## 47.4 泛型

```python
from typing import TypeVar

T = TypeVar("T")

class Stack:
    def __init__(self):
        self._items: list[T] = []

    def push(self, item: T) -> None:
        self._items.append(item)

    def pop(self) -> T:
        return self._items.pop()
```

Python 3.12+ 更简洁：

```python
from typing import TypeVar
T = TypeVar("T")

class Stack(Generic[T]):
    ...
```

## 47.5 函数类型

```python
from typing import Callable

def apply(func: Callable[[int, int], int], a: int, b: int) -> int:
    return func(a, b)
```

## 47.6 可调用类

```python
class Adder:
    def __call__(self, a: int, b: int) -> int:
        return a + b
```

## 47.7 协议（Protocol）

```python
from typing import Protocol, runtime_checkable

@runtime_checkable
class Printable(Protocol):
    def __str__(self) -> str: ...

def print_it(obj: Printable) -> None:
    print(obj)
```

## 47.8 类型别名

```python
from typing import TypeAlias, Union

Number: TypeAlias = Union[int, float]
```

## 47.9 数据类注解

```python
from dataclasses import dataclass

@dataclass
class User:
    name: str
    age: int
    email: Optional[str] = None
```

## 47.10 类型检查工具

- **mypy**：静态检查
- **pyright**：微软出品，更严格
- **pydantic**：运行时验证

```bash
pip install mypy
mypy mymodule.py
```

## 47.11 注解限制

- Python 不强制注解
- 注解是提示
- 运行时可访问（`__annotations__`）

## 47.12 最佳实践

- 公共 API 加注解
- 复杂函数用 typing
- 用 mypy 验证
- 避免过度注解简单脚本

## 小结

- 注解是提示，不是强制
- Python 3.9+ 用内置泛型
- Optional 表示可空
- 配合 mypy/pyright 验证
