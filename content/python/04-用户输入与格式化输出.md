# 第 1 章 入门基础

# 4. 用户输入与格式化输出

## 学习目标

- 用 input() 接收用户输入
- 用 print() 输出
- 掌握 f-string（推荐）和 format() 方法
- 了解 % 格式化（旧式）

## 4.1 input()

```python
name = input("你叫什么名字？")
print(f"你好，{name}!")
```

input() 永远返回字符串，需要自己转换：

```python
age = int(input("年龄："))
price = float(input("价格："))
```

## 4.2 print()

```python
print("hello")           # 单参数
print("a", "b", "c")     # 多参数，空格分隔
print("a", "b", sep="-") # 自定义分隔符
print("x", end="...")    # 自定义结尾（默认换行）
print(1, 2, 3, file=sys.stdout)  # 输出到指定流
```

## 4.3 f-string（推荐）

Python 3.6+ 起最常用：

```python
name = "Alice"
age = 30
print(f"{name} is {age} years old")
```

支持表达式：

```python
a, b = 3, 5
print(f"{a} + {b} = {a + b}")

# 格式说明
pi = 3.14159
print(f"{pi:.2f}")    # 3.14
print(f"{100:>5d}")  # "  100"（右对齐，宽度5）
print(f"{0.5:.0%}")  # "50%"
```

## 4.4 str.format()

```python
"{} is {}".format("Alice", 30)
"{0} is {1}".format("Alice", 30)
f = {"name": "Alice", "age": 30}
"{name} is {age}".format(**f)
```

## 4.5 % 格式化（旧式）

```python
"%s is %d" % ("Alice", 30)
"%.2f" % 3.14159
```

## 4.6 数字格式化速查

```python
# 千位分隔
f"{1234567:,}"    # "1,234,567"
f"{1234567:,.2f}" # "1,234,567.00"

# 十六进制
f"{255:x}"   # "ff"
f"{255:#02x}"# "0xff"

# 百分比
f"{0.1234:.1%}"  # "12.3%"
```

## 4.7 对齐与填充

```python
f"{'hello':>10}"   # 右对齐
f"{'hello':<10}|"  # 左对齐
f"{'hello':^10}"   # 居中
f"{'hello':*^10}"  # 用 * 填充并居中
f"{'42':05d}"      # 00042
```

## 小结

- input() 返回 str，需要手动转换
- f-string 最易读、最快，优先使用
- 复杂场景用 str.format()
- 对齐与填充用格式说明符
