# 第 8 章 文件与 I/O

# 38. 路径处理

## 学习目标

- 掌握 pathlib.Path
- 学会路径操作
- 避免 os.path 的陷阱

## 38.1 基本用法

```python
from pathlib import Path

p = Path("/tmp/data/file.txt")
p.parent    # Path("/tmp/data")
p.name      # "file.txt"
p.stem      # "file"
p.suffix    # ".txt"
p.suffixes  # [".txt"]
```

## 38.2 创建与拼接

```python
base = Path(".")
p = base / "data" / "sub" / "file.txt"
print(p)  # data/sub/file.txt
```

## 38.3 存在与属性

```python
p = Path("config.json")
p.exists()
p.is_file()
p.is_dir()
p.stat().st_size  # 字节数
```

## 38.4 读写

```python
p = Path("note.txt")
p.write_text("hello")
text = p.read_text()

# 二进制
p.write_bytes(b"\x00\x01")
data = p.read_bytes()
```

## 38.5 遍历目录

```python
# 直接子项
for child in Path("data").iterdir():
    print(child)

# 递归 glob
for f in Path("src").glob("**/*.py"):
    print(f)

# 匹配模式
for f in Path(".").rglob("*.log"):
    print(f)
```

## 38.6 创建目录

```python
Path("logs/2026").mkdir(parents=True, exist_ok=True)
```

## 38.7 重命名与移动

```python
src = Path("old.txt")
dst = Path("new.txt")
src.rename(dst)
# 跨目录用 shutil
import shutil
shutil.move("a.txt", "sub/b.txt")
```

## 38.8 相对与绝对路径

```python
p = Path("data/file.txt")
p.absolute()
p.resolve()  # 解析符号链接
```

## 38.9 符号链接

```python
Path("link.txt").symlink_to(Path("target.txt"))
Path("link.txt").is_symlink()
```

## 38.10 比较 os.path 与 pathlib

```python
# os.path
os.path.exists("/tmp/a")
os.path.join("/a", "b")

# pathlib（推荐）
Path("/tmp/a").exists()
Path("/a") / "b"
```

pathlib 更 OO、可组合。

## 38.11 常见陷阱

```python
# 路径拼接
p = Path("data")
p / "file.txt"  # data/file.txt

# 字符串拼接
p2 = "data" + "file.txt"  # datafile.txt（错）
```

## 小结

- pathlib 优于 os.path
- `/` 拼接路径
- glob 遍历匹配
- mkdir 创建目录
